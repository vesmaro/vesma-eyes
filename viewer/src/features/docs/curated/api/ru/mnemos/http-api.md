# HTTP API mnemos — карта

Mnemos — сервер памяти экосистемы: именно его HTTP-поверхность читает борд
(страницы «Пульс», «Обзор», записи памяти), через неё работают CLI и
MCP-инструменты. Эта страница — карта поверхностей; полный справочник живёт
в хабе mnemos и в этот хаб не дублируется.

## Поверхности

| Поверхность | Что в ней | Где смотреть |
|---|---|---|
| Записи и поиск | CRUD записей памяти, семантический поиск, теги под контрактом тегов | [полный справочник HTTP API](mnemos/user/http-api) |
| Конвейер и фильтры | пятиступенчатая очистка контекста, path-scoped rules | там же, разделы Pipeline и Context filter |
| DLQ и трассировки | dead-letter очередь неудачных записей, трассировки запросов | там же, разделы DLQ и Traces |
| Аутентификация | TOTP-логин, сессионные токены (`Authorization: Bearer`), не-loopback guard | там же, раздел Authentication; фон — [security.md](mnemos/admin/security) |
| Метрики | `/health`, `/metrics`, Prometheus-экспозиция | там же + [metrics.md](mnemos/user/metrics) |
| A2A-сессии | контракт сессий агент-агент: жизненный цикл, конверты | [A2A Sessions API](api/mnemos/a2a-sessions) — тело спеки из репозитория mnemos |

## Соглашения, которые стоит знать до первого запроса

- сервер по умолчанию слушает `127.0.0.1` — публичный порт только за
  обратным прокси с аутентификацией;
- при включённой аутентификации все маршруты, кроме `/health`, `/auth/*`,
  `/docs`, `/redoc`, `/openapi.json`, требуют сессионный токен;
- живая спека всегда доступна на самом инстансе: Swagger UI `/docs`,
  ReDoc `/redoc`, схема `/openapi.json`.

## Почему полный текст не продублирован сюда

Полный HTTP-справочник уже синхронизирован в хаб mnemos
(`mnemos/user/http-api`, тот же пин-механизм). Вторая копия в api-хабе
означала бы два пина одного документа и расхождение копий при любом
дрейфе апстрима — решение зафиксировано в `sync-config.yaml`
(`api_hub.sources.mnemos.exclude`).
