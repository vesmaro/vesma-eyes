## Как это потреблять

1. Frontend-разработчик строит `design/stand/` (статический HTML/CSS/JS, без сборки,
   vanilla) строго по `03`–`06`. Токены копируются из блока `tokens.css` в `02` как есть.
2. Имена существующих токенов **заморожены** (ADR 0006, ui-contract §8): нейро-слой
   только **добавляет** имена; переименование/удаление старых запрещено. Значения
   старых имён эволюционировали — см. таблицу «отличия от v1» в `02-TOKENS.md`.
3. Любое отклонение от спеки при реализации — назад к дизайн-лиду, не молча.

## Вне скоупа каталога

- Продуктовые роуты и поведение бэкенда — не здесь (см. `ui-contract.md`, ADR-канон).
- Полный «Атлас»-граф (1k+ узлов, sigma.js) — будущая фаза, в стенд не входит.
- `web/` и `viewer/` в этом worktree не трогаем — это замороженная база для сверки имён токенов.

## Срез v11 — «Живой слой»: аксон и три класса импульса (эстафета ME-060)

Ветка `experiment/living-upgrade-v11` (база = v10). Спека среза —
`docs/14-LIVING-UPGRADE.md` (дельта к `docs/08-LIVING-NEURON.md`): аксон как
единственный эфферент, классы импульса событие/внимание/ошибка, SSE-словарь
v2 (`task.*`/`owner.*`), карта «что кормит И3/И4/V3», честный gzip-факт
против бюджета ≤ 8 KiB.

Как поднять стенд (исполняет ТЛ, у дизайнера нет shell):

```bash
cd design/stand && python3 -m http.server 8125
```

- Демо-витрина слоя: `http://localhost:8125/living.html` — грамматика,
  анатомия, мёртвые состояния, деградация FPS, V3-концепт.
- **Дефолт слоя — «Спокойный»** (канон объединения, `docs/11` §3.3): на любой
  странице вздохов и курьеров нет, события — тинты. Полная витрина — той же
  страницей с `?living=full` (вкладочный оверрайд, настройку не портит;
  другие параметры: `?living=calm|off`, `?demo=0` — демо-лента выключена).
- Управление: клик по Нейре в топбаре — пауза слоя; Настройки → «Живой слой» —
  полный контроль; витрина (`living.html`, `js/living-demo.js`) и
  `styles/living.css` — служебные, в продукт
  (и в living-чанк) не входят.
- Бюджет: гейт ≤ 8 KiB gzip применяется к dist-чанку волн И3/И4; замер
  источника — `gzip -c design/stand/js/living.js | wc -c`, факт вносится в
  `docs/14` §8.
