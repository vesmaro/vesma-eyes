# 11 — Вердикт АРХКОМ по сходимости с основной линией (2026-09-29)

> Полный протокол: `~/.gcw/architectural-committee/2026-09-29-design-convergence.md`.
> Вердикт комитета: **accept-with-conditions** (три позиции единогласно).

## Суть

Strangler поверх И0 подтверждён. Роли: **стенд = эталон вида и словаря
(read-only с И1); main = единственный источник живой механики**. Ветка
слияния — от 2b7c5e8, еженедельный rebase.

## Фазы (с поправками комитета)

- **И1** Shell + развязка Коры (оболочка/композер — из стенда, данные — slice 1-2 main).
- **И2** Кит ui/* срезами «по потреблению» + honest-слоты как контракт каркаса.
- **И3** Обзор = слияние с cockpit Ф2; каркас Коры v7; Живой слой V1 (жилы).
- **И4** Память + композер (React) + Живой слой V2 (отзывчивая Нейра).
- **И5** Остальное. V3 (проактивная Нейра) — отдельная волна вне плана.

## Ключевые условия (полный список — в протоколе)

1. Базлайн-блокер: инструментирование событий борта + ≥7 дней базлайна на main до merge.
2. Journey-приёмка владельцем каждой фазы — формальный гейт (ноль blocker/major).
3. Живой слой при мерже выключен; дефолт — «Спокойный»; «Полный» — по приёмке.
4. «Одна реализация на понятие»: палитра — движок main/вид стенда; Кора — данные main/оболочка стенда.
5. Golden-токены И0: изменение значений — осознанным коммитом; canvas-лойер — отдельный чанк + бюджет.
6. Honest-паттерны main (HonestLine, слоты) — контракт И2.
