# W1b «Колодец — орган состояния» — blueprint (ME-071, дизайн-лид, 2026-10-01)

## DIRECTION (кратко)
Тихий созерцательный инструмент, один смелый жест — тёмный купол колодца. Орган состояния = физиология организма (тон в ткани), НЕ бейджи/алерты. Диски: фигурация (depth-композиция остаётся, колодец обрастает тканью), хроматический бюджет (сигнальный цвет несут только реальные данные, субстрат монохромен), экономика движения (ноль нового RAF в покое; дыхание несёт CSS; бусины живут только пока живо событие).

Морфология — гибрид «паутина-субстрат + глубинный граф данных»: внутри купола детерминированная ткань ~96 точек и коротких нитей (чистая функция фиксированного seed, независима от данных; силуэт v12: колонии ниже зеркала воды), монохромный миелин; ПОВЕРХ — нетронутый слой данных (42 памяти, ≤30 реальных рёбер, пробуждение как сдано). Субстрат никогда не тонируется, не носит бусины, не отвечает на hover — цвет без источника невозможен конструктивно. Близостные рёбра v12-стенда в проде ЗАПРЕЩЕНЫ (фабрикуют ложные связи — нарушение честностного гейта). Субстрат = первые потребители golden-токенов --web-node/edge/wave-alpha, --duration-web-idle. Закрывает риск «чёрной ямы»: первый кадр текстурен до пробуждения.

## IMPLEMENTATION (файлы)

### wellGraph.ts
- НОВОЕ: чистая функция `buildSubstrate(): { points; strands }` — без входных данных: фиксированный seed, ~96 точек (константа WELL_SUBSTRATE_CAP), 4–5 «колоний» (центры y≈0.45–0.75H, радиальный разброс pow(u,0.65)), верхние 16% (TOP_MARGIN, зеркало воды) свободны; нити = точка ↔ 1–2 ближайших соседа в радиусе ≤0.2W, degree ≤3, нитей ≤110. Детерминизм: техника stableUnit (соль фиксированная, от памяти не зависит).
- Расширить проекцию `buildWellGraph` опциональным `title?: string | null` (поле уже приходит из useMemories) — для рид-аута.
- Экспортировать типы и капы.

### WellHero.tsx
- Рендер субстрата ПЕРВЫМ: `<g className="well-substrate" aria-hidden>` (точки fill/нити stroke = --myelin-hairline), затем данные. z: субстрат → рёбра → узлы → HUD.
- HUD-слот рид-аута: средний слот нижней полосы (min-w-0 truncate font-mono text-sm tabular-nums text-foreground-secondary), aria-hidden, pointer-events-none, пуст = не рендерится.
- Атрибуты окна: data-well-tone="none|active" + инлайн --well-tone (rgb из органа).
- Halo hover: <circle>-ринг r = node.r + 3, stroke var(--myelin-strong), условный.
- Подключение органа: useEffect с void import("@/living/wellOrgan") по образцу LivingLayer.tsx (cancelled-флаг, StrictMode-безопасный деструктор), передача ref окна.

### living/wellOrgan.ts — НОВЫЙ, ленивый чанк web-tones
- `mountWellOrgan(win: HTMLElement): () => void`. Внутри: createTones(cssReader, isLivingMuted) + subscribeLiving (второй слушатель — Set в livingFeed позволяет; движок не трогать).
- Шаговый (НЕ RAF-цикл) тон: событие/health/update → пересчитать цвет, выставить --well-tone + data-well-tone; возврат по таймерам окна (80% окна → цвет базы, 100% → none); hold-потолок из --duration-tone-hold. Кроссфейд делает CSS transition fill var(--duration-tone-fade); reduced-зеркала (1500/0ms) дают статичный тинт автоматически. Пока нейтраль и нет бусин — НОЛЬ таймеров и кадров.
- Бусины: только liveLayer==="live" && !reduced && !muted; ≤2 живых; ребро — детерминированно хешем вида события (паттерн hash() движка); направление from→to; проход 400–1600ms; след — частичное перекрашивание ребра с затуханием 1.5s; лёгкий RAF только пока жива бусина, пауза на document.hidden.
- Hover: слушатели на окне; pointermove → координаты viewBox (getScreenCTM().inverse()), ближайший узел в радиусе ≈18; рид-аут «title · YYYY-MM-DD» (нет title → id.slice(0,8)); Esc — сброс; coarse-указатель — pointerdown, автосброс 2.5s; очистка по pointerleave. При muted рид-аут и гало работают (это данные/ myelin, не живой слой).
- Деструктор: снять слушатели/таймеры/RAF, идемпотентен (StrictMode).

## ПРИЁМКА — скрин-гейт «чёрного купола» (отказ слоту при любом провале)
- Обе темы, один купол: узлы/рёбра читаемы в dark и light; субстрат/тон не протекли за скоуп [data-well-window].
- Иерархия ткань < данные: субстрат тише данных (альфа ≤ --web-wave-alpha); «фон за ценой данных» = отказ.
- HUD на veil: текстовые пиксели внутри канвы на --hud-veil; рид-аут не перекрывает чип/тикер; фокус-ринг чипа не заслонён (2.4.11).
- Канва не чёрная яма: первый кадр текстурен (субстрат).
- Анти-фейк-аудит: заглушка health+SSE → нейтраль, ноль цветного.
- Тон-хореография: кроссфейд 1200ms; сирень не сосуществует с error/warn; error >60s без мерцания.
- Бусины: только живые события, ≤2, по реальным рёбрам, в покое ноль.
- Reduced: статика сразу, тинт 1.5s, ноль анимаций.
- Hover-честность: курсор не pointer, узлы не в tab-порядке, Esc гасит, факты доступны вне колодца.
- Производительность: в покое ноль новых RAF; скрытая вкладка не считает; budget зелёный обоими числами.
- Тон-дублирование (1.4.1): состояние читается не только цветом (тикер, HUD, чип; хаб — размером).
