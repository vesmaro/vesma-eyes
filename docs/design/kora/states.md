# Kora Rethink — State Matrix

## 1. Каркас и левая панель (навигация)

| ID | Условие | Левая панель | Переходы |
| -- | ------- | ------------ | -------- |
| K-NAV-PENDING | реестр/исполнители в полёте | скелетоны (чисел нет — честно) | → любой |
| K-NAV-NO-EXEC | реестр исполнителей = 0 (факт) | честная empty — факт констатируется БЕЗ действия: CTA «подключить агента» живёт ОДИН раз на экране, в центре воркзоны (канон ME-072; ссылка → /agents/harnesses стоит там, не в панели) | — |
| K-NAV-NO-SESS | исполнители есть, сессий 0 | честная empty + линк /system/status | — |
| K-NAV-ERROR | 5xx/транспорт | error + retry (гейты — не каркас) | retry |
| K-401 | любой read ответил 401 | гейт KoraSignInCta, документ-флоу (как сегодня) | повторный вход |

## 2. Центр — режимы

| ID | Условие | Центр | Переходы |
| -- | ------- | ----- | -------- |
| K-EMPTY | сессия не выбрана И роут не /kora/hermes (реализация — blueprint §5: режим чата роутовый, от фильтра не зависит; hermes-фильтр без выбранной сессии = то же приглашение) | приглашение (Эфир теперь в метe) | клик сессии → режим B; запись «Чат с кластером» → /kora/hermes (режим C) |
| K-ZCODE | сессия zcode/vscode/pi (live/idle) | полный транскрипт + инструменты + композер с отложенной отправкой | выбор другой сессии; копия ссылки |
| K-ZCODE-DEAD | сессия dead (процесс gone) | как K-ZCODE, поле выключено + нота «прервана» видима без ховера | — |
| K-HERMES-LIVE | сессия hermes выбрана | СПЛИТ: чат (история сессии + локальные ходы, композер РЕАЛЬНЫЙ, модель, переключатель) + «Все ходы» (полоса/разворот) | → K-CHAT-* |
| K-CLUSTER | /kora/hermes | сплит как K-HERMES-LIVE, история = якорная api_server-сессия или честный чистый лист | — |
| K-NOT-FOUND | курсор кончился, id нет | not-found + назад в /kora (документ-флоу) | — |

## 3. Центр — чат (hermes-режимы), статусы отправки

| ID | Условие | Чат-зона | Переходы |
| -- | ------- | -------- | -------- |
| K-CHAT-IDLE | композер пуст/набран | нота: «цельно, не потоково; лимит — 12/мин» + нота неперсистентности | Enter/кнопка → K-CHAT-PENDING |
| K-CHAT-PENDING | POST в полёте (до 60с) | «Отправляем… (ответ придёт целиком, до 60 секунд)»; композер и кнопка disabled; БЕЗ фейкового typing | ответ → append; ошибка → K-CHAT-ERR* |
| K-CHAT-ERR-TRANSPORT | 503 hermes_off / 502 unavailable | «Не доставлено: <человеческая причина>»; ТЕКСТ ОСТАЁТСЯ в поле; статус источника в левой панели показывает off-карточку | повтор после устранения |
| K-CHAT-ERR-RATE | 429 (12/60с исчерпан) | человеческая причина из ответа (Retry-After если есть); черновик цел; НЕ выдуманный таймер | повтор позже |
| K-CHAT-ERR-VALID | >8000 знаков / >20 ходов | клиентский кап в maxLength + срез хвоста истории (сегодняшняя механика), серверная валидация именует себя | правка текста |
| K-CHAT-UNKNOWN-FORMAT | ответ пришёл, текст не распознан | «Ответ получен, но текст не распознан…» — названо, не сфабриковано | — |
| K-CHAT-MODEL-404 | модель отклонена hermes | человеческая причина в линии ошибки; выбор модели возвращается к дефолту (пользователем, не молча) | — |

## 4. Второстепенная зона «Все ходы»

| ID | Условие | Зона | Переходы |
| -- | ------- | ---- | -------- |
| K-MOVES-COLLAPSED | дефолт | полоса 40px: caps «ВСЕ ХОДЫ · N» + Развернуть | разворот кликом/швом |

| K-MOVES-LOADING / -ERROR / -EMPTY | пагинация в полёте / ошибка / пусто | скелетон / error+retry / честная пустая строка (поиск: «совпадений: 0») | — |
| K-MOVES-SEARCH | введён запрос | ВСЕ кат-фолды раскрыты (матч внутри свёрнутого хода обязан быть виден); счётчик честный | очистка → как было |

## 5. Правая мета-панель

| Блок | Дефолт | Пустой/ошибочный вид |
| ---- | ------ | -------------------- |
| О СЕССИИ | развёрнут при выбранной сессии; без сессии — свёрнут с честной строкой | поля деградируют (покрытие «неизвестно») |
| ДАЙДЖЕСТ | свёрнут | внутри честная empty (источник релея не прибыл) — не фейк-жизнь |
| ЭФИР | развёрнут | пустое кольцо = честная пустая строка; один маунт на workspace |
| ПОКРЫТИЕ | свёрнут | скрыт, если coverage от сервера нет |

## 6. Респонсив-лестница

- ≥xl (1280+): полный трёхзонный каркас + сплит центра.
- lg..xl (1024–1279): две колонки — центр + МЕТА; блоки НАВИГАЦИИ живут
  секциями вверху мета-панели (один скролл, навигация первой); сплит центра
  сохраняется.
- <lg: документ-флоу как сегодня: навигация → центр (чат/транскрипт) →
  «Все ходы» свёрнутой секцией → мета секциями; ниже sm чат/транскрипт
  во всю ширину; цели касания ≥48px.

Решения по открытым вопросам (приняты ТЛ по рекомендациям Design Lead, докладываются владельцу):
1. Чат в zcode-сессиях — честно отложенный композер сохраняется (поле + черновик + видимая причина); притворный чат не делается; «стиринг zcode» — будущий серверный срез.
2. Дефолт зоны «Все ходы» — свёрнутая полоса 40px; разворот и высота персистятся.
