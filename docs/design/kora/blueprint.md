deep-link «hermes:<native>» едет через живой messages-роут, id реестра — через

(zcode/vscode/pi — read-only, zcode_reader.py, редакция на сервере); мост
hermes: GET /status, GET /sessions (живой pull+upsert, 12/60с), GET
/sessions/{id}/messages (12/60с, общий лимитер), POST /chat — ui-only
(владелец), НЕ-потоковый, ≤20 ходов × ≤8000 знаков, `model` опционален
(дефолт hermes-4.5-405b), ответ {ok, source «hermes · real-time», model,
completion verbatim}. SSE-стрим чата и стиринг hermes — будущие срезы,
записаны сервером как gap, в этой волне не проектируются.

## 2. Direction (вердикт)

Трёхзонный каркас Коры (директива 2026-10-22): ЛЕВО — панель навигации
сессиями (хосты/агенты + сессии контекста, статусы идёт/ждёт), ЦЕНТР —
основная зона ЧАТА (история, композер, выбор модели, переключатель сессий)
+ второстепенная зона «Все ходы» под горизонтальным швом (сырой транскрипт,
свёрнутые ходы — канон), ПРАВО — информационная мета. Честный режим: сплит
«чат+ходы» существует ТОЛЬКО там, где чат реален (hermes: живая сессия или
кластерный чат); zcode/vscode/pi-сессии — полностраничный транскрипт с
честно отложенным композером (канон 07a §1 не нарушаем: нет серверной
возможности записи — нет притворной отправки). Пульт распускается: Дайджест
и Эфир — блоки меты, бейдж «ждут» — чип в шапке, высотная механика Пульта
переезжает на зону «Все ходы». Один чат-поверхность в продукте — Кора;
в поле «Агенты» сессия = превью только-чтение + «Открыть в Корe» (§9).

## 4. Состав зон

ЛЕВАЯ ПАНЕЛЬ «Навигация» (новая): Блок «Хосты и агенты» (KoraTree как есть) →
Блок «Сессии · контекст» (KoraSessionList: строки с live-точкой, состоянием,
возрастом; быстрые фильтры идут за ней) → закреплённая запись «Чат с
кластером» (только в hermes-контексте) → HermesSourceLine (hermes-контекст).
Один скролл, шов col-resize, персист vesmaro.koraLeftW (константы
KORA_NAV_DEFAULT/MIN/MAX — при имплементации; ориентир 280/220/380).

ЦЕНТР, основная зона «Чат» (hermes-режимы): шапка чата — переключатель сессий
(select из контекстных сессий, зеркалит левую панель, пишет роут) + выбор
модели (select из моделей источника; дефолт preselected) + бейдж источника
«hermes · real-time» как DATA. История = сообщения сессии (роли user/assistant,
грамматика ChatLine) + локально добавленные ходы; композер существующий
(Enter — отправить, Shift+Enter — перенос, кап 8000, «Отправляем… до 60 с»,
черновик остаётся при ошибке, unknown-format честно). НОВАЯ честная нота под
композером: «Ответы чата не записываются в транскрипт сессии hermes» — POST
/chat бессостояний, запись в источник сервером не предусмотрена; нить
переписки живёт вью, перезагрузка показывает хранимую историю сессии.

ЦЕНТР, второстепенная зона «Все ходы»: свёрнутая полоса 40px (caps «ВСЕ ХОДЫ ·
N» + Развернуть) → развёрнутый HermesTranscript сегодняшней грамматикой:
группировка диалог/raw-walk, свёрнутые ходы (RawWalkFold, `<details>`) —
КАНОН, kind-теги, reasonings-кат, имена tool-call, SCARLET-редакция,
провода raw→ответ, поиск с честным счётчиком. Шов row-resize сверху: авто ≤280
/ фикс 160–420, гистерезис <120 = свернуть, сброс = авто, персист
vesmaro.koraMovesH (механика Пульта переезжает целиком).

ПРАВАЯ ПАНЕЛЬ «Мета»: блоки один скроллом, сворачиваемые — «О СЕССИИ»
(переезд из KoraSessionList: начало/активность/покрытие/источник/копия
ссылки; развёрнут при выбранной сессии), «ДАЙДЖЕСТ» (крыло Пульта; свёрнут —
честно пуст до релея), «ЭФИР» (крыло Пульта, живое кольцо; развёрнут),
«ПОКРЫТИЕ» (CoverageLegend; свёрнут). Дефолты: О СЕССИИ + ЭФИР развёрнуты,
ДАЙДЖЕСТ + ПОКРЫТИЕ свёрнуты.

Шапка: к бейджу «ждут владельца» (переезд из Пульта, тот же линк /tasks/inbox,
скрыт пока счётчик неизвестен) + select-фильтр как сегодня.

## 5. Routing

- /kora — без сессии: левая панель + приглашение в центре + мета.
- /kora/:sessionId — БЕЗ ИЗМЕНЕНИЙ (id реестра и «hermes:<native>»).
- /kora/hermes — НОВЫЙ, зарезервированный сегмент (не пересекается с id
  реестра): кластерный чат, deep-linkable; выбирается записью «Чат с
  кластером». Селект фильтра в шапке продолжает писать контекст (?host=),
  режим чата больше не зависит от «фильтр=hermes и ничего не выбрано».

## 6. Reuse map (ничего не реимплементим)

- KoraTree, KoraSessionList (вместе с блоком «О сессии»), HermesSourceLine,
  CoverageLegend — переезжают, код не переписывается.
- KoraHermesChat — становится основой основной зоны чата (история якоря +
  локальные ходы, композер, статусы); добавляются переключатель сессий и
  выбор модели.
- HermesTranscript + useTranscriptWires + KoraTranscript (RawWalkFold,
  RoleChip, RedactionMark, Highlighted) — зона «Все ходы» без изменений.
- KoraComposer — режим zcode без изменений (отправка отложена — канон).
- KoraResizeHandle + koraFrameStorage — все три шва (левый, правый, высота
  «Всех ходов»); ключи: +vesmaro.koraLeftW, +vesmaro.koraMovesH;
  −vesmaro.koraPultH, −vesmaro.koraEtherW (Пульт распущен).
- useKoraHermesTranscriptPages — ОДИН экземпляр на сессию на уровень
  workspace: чат фильтрует user/assistant, «Все ходы» показывает группы;
  двойного чтения messages нет.
- koraEtherStore/useKoraEtherBridge — одно кольцо, одна посадка (мета).
- «О сессии»/копия ссылки, честные empty, 401-гейт, retry, not-found —
  сегодняшний документ-флоу, не трогаем.

## 7. Серверная зависимость (малая, аддитивная)

Выбор модели требует списка: расширить GET /api/kora/hermes/status полями
`models[]` + `default_model` (аддитивно, вне замороженного артефакта недели 0,
ui-only — прецедент HermesBridgeStatus; статический проверенный список в
server/hermes_client.py). Альтернатива-фолбэк, если серверный лег уходит в
отдельный срез: select из константы дефолта без списка — но тогда «выбор
моделей» сводится к дефолту, честно подписанному. Рекомендация: лег в KW2.

## 8. Motion & perf risks

- Никакой анимации размеров на швах (07l §0): drag мгновенный, transition off
  на время drag; тоглы полос «Все ходы» — duration-instant; входы/выходы парой;
  reduced-motion таблица 06 §7. Глоу-бюджет не трогаем, амбиента нет.
- ОДНО чтение messages на сессию (чат + ходы из одного хука) — иначе двойной
  трафик и рассинхрон.
- Follow-tail живёт в зоне, которая развёрнута и на дне; у чата — свой, у
  «Ходов» — свой; pending-ответ автоскроллит только чат. Два автоскролла не
  дерутся (правило: следует развёрнутая зона, пользователь ушёл вверх — не следим).
- Свёрнутые ходы НЕ рендерить раскрытыми: RawWalkFold остаётся `<details>`;
  пагинация 50/страница — единственная граница DOM. Виртуализация НЕ в скоупе;
  запись в бэклог: замерить на транскриптах >500 видимых строк, решать по
  цифрам, не по вкусу.
- SSE одно (Эфир-мост) на workspace; чат не-потоковый — никаких фейковых
  typing-индикаторов (канон).

## 10. Acceptance criteria (гейты воркерам)

1. ≥xl: три зоны, 100vh, страница не скроллит; все швы с полным клавиатурным
   путём и персистом на commit; «стык без зазора» сохранён.
2. Свернутые ходы = канон: RawWalkFold-грамматика «Всех ходов» байт-в-байт
   сегодняшняя (снапшоты HermesTranscript не меняются без причины).
3. hermes-режимы: переключатель сессий пишет роут (deep-link назад работает),
   выбор модели уходит в POST /chat, 12/мин-нота видна, черновик переживает
   ошибку, неизвестный формат назван; нота неперсистентности ответов видна.
4. zcode-режим: композер с отложенной отправкой и видимой причиной не
   регрессировал; dead-сессия — выключенное поле с нотой.
5. Пульт отсутствует в структуре; бейдж «ждут» в шапке — реальный счётчик
   UI-30, скрыт пока неизвестен; i18n ru/en синхронно, снапшоты обновлены.
6. Одно чтение messages на сессию (проверка сетью: 1 запрос на пагинацию);
   Эфир монтируется один раз.
7. Состояния из states.md покрыты тестами (снапшоты + a11y: регионы с
   aria-label, aria-expanded на полосах, фокус h2 при смене сессии).
8. /kora/hermes резолвится, /kora/:sessionId и 401/error/not-found не
   регрессировали; kora.entered метрика жива.
