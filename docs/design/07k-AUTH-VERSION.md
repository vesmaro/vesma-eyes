## 0. Решения поверх брифа (записаны до проектирования)

| Вопрос брифа | Решение | Почему |
| --- | --- | --- |
| Поиск в топбаре для анонима: скрыть? | **Скрыть** | Поиск выдаёт содержимое памяти — сам по себе гейт-действие. Пустой поиск с гейтом по Enter — тупик; вместо него слот отдают кнопкам «Войти»/«Регистрация» |
| Счётчик «▸2» и колокольчик для анонима | **Скрыть** | Живая операционная активность агентов — содержимое, не сводка; клик вёл бы в гейт. LIVE-пилюля остаётся: это статус связи, а не контент |
| Галерея и Документы | **Публичны (рекомендация)** — вопрос владельцу (§11) | Витрина стенда и документация — типичные публичные поверхности |
| Роль «владелец» в строке футера | **В tooltip и в меню чипа**, не в строке | Строка «vesmaro-eyes 1.41.0 · вы: abyss» — потолок 232px сайдбара; роль дублируется в двух местах рядом (07a §1: статус не одинок — роль читается в меню чипа) |
| Превью закрытого контента за гейтом (blur) | **Запрещено** | Пейвол-превью — тёмный паттерн; гейт чистый, контент не рендерится |
| Точка статуса в футере — glow? | **Без glow** | Glow-бюджет `06` §6: ≤2 источников; live-пилюля топбара уже занимает один. Точка — статичный цвет + текст |
| Регистрация в проде | Спека проектирует вкладку, продукт-политика — вопрос владельцу (§11); в UI честная строка «первый аккаунт становится владельцем» | Директива: продуктовая история «первый запуск создаёт владельца» |

## 1. Версия и статус сессии (футер)

### 1.1 Единственный источник

`data.js`: константы `STAND.version = "1.41.0"` и `STAND.slice = "v6"`.
Никаких дублей версии в разметке страниц: футер сайдбара, футеры страниц вне
Shell (pair, auth) и подпись Галереи читают одну константу. Страницы вне Shell
сейчас не подключают data.js — подключают (или frontend выделяет
stand-meta-модуль; контракт один: константа живёт в data.js).

### 1.2 Место и анатомия

Сайдбар, подвал — слот строки «Стенд дизайна · демо-данные» (левый нижний угол,
как просил владелец). Строка заменяет stand-note, честность стенда переезжает
в tooltip:

```
│ ⌘K Палитра          │
│ ? Шпаргалка         │
│ ▦ Галерея    ⌗стенд │
│ [ Свернуть       ]  │
│                     │
│ ● vesmaro-eyes 1.41.0 · аноним        ← строка статуса, --text-caps 11px
└─────────────────────┘
```

- **Состав строки**: точка 6px + `vesmaro-eyes <версия>` + `·` + статус.
  Статусы: `аноним` / `вы: <имя>` (роль — в tooltip и меню чипа, §0).
- **Точка**: аноним — `--color-text-muted` (нейтральная); авторизован —
  `--color-success`, без glow (§0). Статус никогда не цветом одним — текст
  рядом (WCAG 1.4.1).
- **Типографика**: `--text-caps` (11px) + `--tracking-caps`,
  `--color-text-muted` (5.0:1 на well — AA); версия и числа — не моноширинные
  (строка метаданных, не данных; tabular-nums достаточен). Строка не
  интерактивна: без hover/focus, не конкурирует с навигацией (правило брифа).
- **Tooltip** (`title`): «Стенд дизайна, срез v6 · демо-данные» для анонима;
  «Стенд дизайна, срез v6 · роль: владелец · вход 2 ч назад» для
  авторизованного. Возраст входа — человеческим интервалом (07a §1.5).
- **Свёрнутый сайдбар** (56px): строка схлопывается в точку + короткую версию
  «1.41» (влезает в 56px, mono-подобная точность не требуется), tooltip —
  полный. Версия не исчезает из UI ни в одном режиме.
- **Мобильный сайдбар** (<768px, drawer): строка внизу drawer'а без изменений.

### 1.3 Страницы вне Shell

- **pair.html**: вторая строка `.pair-foot` — та же строка статуса (пейринг
  доступен анониму, показывает реальное состояние сессии).
- **auth.html**: строка в футере страницы (§4) + ссылка «Статистика — на
  Обзоре →».

### 1.4 State-матрица футера-статуса

| Компонент | Матрица |
| --- | --- |
| Строка статуса | anonymous (muted-точка) / authorized (success-точка) / collapsed (точка + «1.41») / mobile-drawer / reduced-motion (без особенностей — строка статична всегда) |
| Tooltip | показывает версию-срез всегда; роль и возраст входа — только у авторизованного |
| Запрет | строка никогда не кнопка и не ссылка (вход ведут топбар/гейт/auth); два источника правды версии запрещены |

## 2. Модель доступа: публичная поверхность

### 2.1 Таблица публичности

| Раздел | Аноним | Основание |
| --- | --- | --- |
| Обзор `/` | **публичен** — сводка без содержимого (§6) | директива: «общая информация и данные (статистика, количество)» |
| Память (Записи, Поиск, Пульс, Теги) | **гейт** | содержимое памяти |
| Задачи (Канбан, Список, Входящие, Архив) | **гейт** | работа владельца и исполнителей |
| Агенты (Исполнение, Хосты, Подключить) | **гейт** | операционные данные, SSH-доступ |
| Кора | **гейт** | транскрипты сессий |
| Документы | **публичен** *(рекомендация — вопрос владельцу §11)* | документация обычно публична |
| Система (Статус, Настройки…) | **гейт** | служебная зона |
| Рабочий стол (Терминал, Проводник) | **гейт** | доступ к машинам |
| Галерея | **публична** *(рекомендация — вопрос владельцу §11)* | витрина стенда |
| pair.html | **публична** | точка входа устройства, канон `07h` |
| auth.html | **публична** | точка входа человека (новая) |

Инвариант: «публичен» у Обзора = **агрегаты без содержимого**; публичность
Документов/Галереи — до решения владельца реализуется как гейт (переключение —
одна строка в конфиге публичности, §11).

### 2.2 Навигация анонима — одно поведение на всех путях

- **Сайдбар**: все домены остаются видимыми (recognition over recall, канон
  `03` §3 «не прятать, показывать с пояснением»). У гейт-домена счётчик
  заменяется иконкой-замком (lucide `lock` 14px, `--color-text-muted`, ≥3:1 —
  1.4.11) + tooltip «Откроется после входа». Строки публичных доменов — без
  замков. Свёрнутый сайдбар: замок виден под иконкой домена.
- **Клик по замку / хоткей `g m` / пункт палитры** → переход на страницу
  раздела, которая рендерит **гейт-экран в слоте контента** (§3). URL-first:
  никаких редиректов и петель; `/memories.html?id=T-128` для анонима = тот же
  гейт (id не просачивается ни в разметку, ни в title).
- **Палитра анонима**: публичные разделы + гейт-разделы с пометкой замка
  (ведут в гейт) + действия «Войти», «Создать аккаунт». Сущности (записи,
  хосты, задачи) и действие «Дать задачу» скрыты — содержимое.
- **Глобальный поиск скрыт** (§0); хоткей `/` для анонима не действует (guard
  по сессии, в шпаргалке хоткеев строка помечена «после входа»).
- **Шпаргалка `?` и палитра `Ctrl+K`** работают у анонима — навигация не секрет.

### 2.3 Топбар — два состояния

```
АНОНИМ
┌──────────────────────────────────────────────────────────────────────────────┐
│ ◉ vesmaro-eyes                              ●live  [Войти] [Регистрация] RU|EN ◐│
└──────────────────────────────────────────────────────────────────────────────┘

АВТОРИЗОВАН (владелец)
┌──────────────────────────────────────────────────────────────────────────────┐
│ ◉ [ ⌕ Поиск по памяти и задачам… / ]      ●live ▸2 ( bell ) (A abyss ▾) RU|EN ◐│
└──────────────────────────────────────────────────────────────────────────────┘
```

- **Аноним**: слот поиска пуст (не серая заглушка — места нет вовсе);
  справа primary-ghost пара «Войти» + «Регистрация» (компоновка с RU|EN и
  темой: кнопки левее тумблеров, разделитель-миелин между зоной входа и
  настройками). LIVE-пилюля остаётся. ▸2, bell — скрыты (§0).
- **Авторизован**: поиск возвращается, ▸2 и bell возвращаются, пара
  «Войти/Регистрация» заменяется чипом пользователя (§5.2).
- **Мобильный (<768px)**: статус-зона сжимается до live-точки; аноним —
  кнопка «Войти» (иконка+текст), «Регистрация» уходит в меню «⋮»;
  авторизован — чип-иконка «A».
- **Кнопка «Войти»** — primary-solid (единственная primary вьюпорта у анонима);
  «Регистрация» — ghost. Матрица — `05` §2.1. Цели ≥24px, мобильный 44px.

## 3. Гейт-экран (внутри Shell, слот контента)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Память / Записи                                                  ⌘K          │
│                                                                              │
│                                    ◉                                         │
│              Раздел «Память» откроется после входа                           │
│      Записи, поиск по смыслу, пульс и теги — содержимое памяти.              │
│      Статистика открыта всем — она на Обзоре.                                │
│                                                                              │
│              [ Войти ]    Создать аккаунт                                    │
│                                                                              │
│              ▸ Что я увижу после входа                                       │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **Анатомия** (правило 5 секунд + пустое состояние `07a` §1.2: почему +
  кнопка + куда ещё): знак ириса 40px (статичный, без дыхания — дыхание
  принадлежит бренд-ирису топбара, `06` §4) → H1 по шаблону владельца
  «Раздел „<Имя>“ откроется после входа» → одна строка «что внутри» → одна
  строка «куда ещё посмотреть» («Статистика открыта всем — она на Обзоре»,
  ссылка на `/`) → кнопки → свёрнутый блок.
- **Кнопки**: «Войти» primary → `auth.html?return=<текущий путь+query>`
  (encodeURIComponent); «Создать аккаунт» ghost → тот же адрес с
  `&tab=register`. Матрица — `05` §2.1.
- **«Что я увижу после входа»** — свёрнутый блок (паттерн `07h` §2
  «Что это даёт?»: шеврон ≥24px, 240ms `--ease-enter`, состояние персистентно
  в сессии). Внутри — 2–3 строки конкретики раздела (таблица ниже), без
  обещаний того, чего нет в стенде.
- **Крошки остаются** («Память / Записи») — пользователь видит, куда пришёл;
  H1 гейта получает фокус при переходе (`tabindex="-1"`, polite — канон
  `03` §8). Анонимный вход по прямому URL — тот же экран, содержимое раздела
  не рендерится (§0).

Копирайт гейтов по разделам (H1 — шаблон владельца, «внутри» — одна строка):

| Раздел | Строка «что внутри» |
| --- | --- |
| Память | «Записи, поиск по смыслу, пульс и теги — содержимое памяти» |
| Задачи | «Канбан, список, входящие и архив — работа и поручения» |
| Агенты | «Исполнение, хосты и подключение новых машин» |
| Кора | «Журнал сессий всех хостов: что агент делал и что говорил» |
| Система | «Статус, устройства и трассировки — служебная зона» |
| Рабочий стол | «Терминал и проводник — экспериментальная зона стенда» |

### 3.1 State-матрица гейт-экрана

| Компонент | Матрица |
| --- | --- |
| Гейт-блок | default (любой гейт-раздел) / с return-параметром (после отказа входа пользователь вернулся — строки те же, фокус на H1) / reduced-motion (появление мгновенно) |
| Кнопки «Войти»/«Создать аккаунт» | `05` §2.1 (primary/ghost) |
| Свёрнутый блок | collapsed / expanded (персистентно) / focus на шевроне |
| A11y | H1 фокусируется и объявляется polite; блок — disclosure-кнопка с `aria-expanded`/`aria-controls`; ссылка «на Обзоре» — настоящий `<a>` |

## 4. auth.html — публичная страница входа

Паттерн `07h` §1: вне Shell, свой хедер (знак ириса + заголовок + тумблер
темы), центральная колонка max-w-md, фон `--color-bg-base`, карточка на
`--color-bg-well` `--radius-lg`. Единственный glow страницы — focus-зрачок
полей (канон публичной страницы `07h` §7).

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ◉ vesmaro-eyes · Вход                                                   ◐    │
│                                                                              │
│         ┌────────────────────────────────────────┐                           │
│         │   В ХОД   |   РЕГИСТРАЦИЯ              │ ← вкладки-сегмент         │
│         │ ────────────────────────────────────── │                           │
│         │  Имя пользователя                      │                           │
│         │  [ abyss                             ] │                           │
│         │  Пароль                            [◉] │ ← показать пароль, 24px   │
│         │  [ ••••••••••                        ] │                           │
│         │                                        │                           │
│         │  [               Войти               ] │ ← primary, loading «Входим…» │
│         │  Ошибка: Неверное имя или пароль.      │ ← вердикт инлайн, не тостом│
│         │  Что проверить: раскладка RU/EN,       │                           │
│         │  регистр букв, Caps Lock.              │                           │
│         └────────────────────────────────────────┘                           │
│         ◑ стенд: любой логин подойдёт — данные не отправляются               │
│                                                                              │
│   ● vesmaro-eyes 1.41.0 · аноним        Статистика — на Обзоре →   [На борт] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 4.1 Вкладки «Вход | Регистрация»

- Сегмент из двух вкладок (`role="tablist"`, стрелки ←/→, `aria-selected`,
  фокус-ринг `--color-focus`); активная вкладка — ирис-подчёркивание 2px
  (≥3:1 — 1.4.11) + текст `--color-iris-bright`. URL-first: `?tab=register`
  — вкладка открывается по ссылке из гейта и топбара, дефолт — «Вход».
- **Вход**: «Имя пользователя» + «Пароль» (тип password, eye-переключатель
  «Показать пароль», клик-цель 24px, `aria-pressed`) + primary «Войти».
  Поля — полный набор `05` §2.5; `autocomplete="current-password"`.
- **Регистрация**: «Имя пользователя» + «Пароль» + «Пароль ещё раз» +
  primary «Создать аккаунт»; `autocomplete="new-password"`. Под заголовком
  вкладки одна строка продуктовой истории: **«Первый созданный аккаунт
  становится владельцем борта»** (директива: первый запуск создаёт владельца).
- **Валидация** — live после первого blur (`05` §2.5): имя короче двух
  символов — «Имя короче двух символов — придумайте подлиннее»; пароли не
  совпадают — «Пароли не совпадают — проверьте второе поле»; пустое поле при
  отправке — «Введите имя» / «Введите пароль».

### 4.2 Исходы (канон `07b` §5)

| Исход | Что происходит |
| --- | --- |
| Успех входа | редирект на `return` (дефолт — `index.html`) + тост на месте прибытия «Вы вошли: abyss» (handoff через localStorage-флаг, как `focus-h1` в shell.js — тост переживает переход). Сессия `vesmaro.authSession` записана до редиректа |
| Ошибка входа | инлайн-вердикт под кнопкой (не тост, `07b` §5.2): заголовок «Неверное имя или пароль» + «Что проверить: раскладка RU/EN, регистр букв, Caps Lock». Фокус переносится на поле имени, `aria-live="polite"`, префикс «Ошибка:» (не цветом одним — 3.3.1/1.4.1) |
| Успех регистрации | тост «Аккаунт создан. Вы вошли: <имя>» → return/Обзор; роль «владелец» записана (первый аккаунт) |
| Ошибка регистрации | вердикт «Аккаунт создать не удалось» + причина (имя занято — «Такое имя уже есть. Возьмите другое») |
| Уже вошёл | открытие auth.html с живой сессией → редирект на Обзор + тост «Вы уже вошли: abyss» (честный исход, не дубль формы) |
| Стенд-честность | постоянная строка-бейдж под карточкой, caps muted: «стенд: любой логин подойдёт — данные не отправляются» + блок демо-фаз (как на pair.html): «ошибка входа», «занятое имя» — исходы проверяемы на стенде |

Кнопка «Войти» в loading — «Входим…» (спиннер 16px, повторный клик
заблокирован); в стенде разрешается мгновенно — состояние в матрице, честность
стенда не имитирует сетевую задержку.

### 4.3 Футер и возврат

Строка статуса (§1.3) + ссылка «Статистика — на Обзоре →» + кнопка возврата
«← На борт» в слоте над карточкой — паттерн `07h` §12 (один слот во всех
состояниях, 44px, primary-outline).

### 4.4 State-матрица auth-вкладок и формы

| Компонент | Матрица |
| --- | --- |
| Вкладки | default/hover/focus-visible/selected (ирис-подчёркивание)/reduced-motion; клавиатура ←/→; `aria-controls` на панель |
| Панель вкладки | видима/скрыта (`hidden`); смена панели — фокус на первый инпут, announce polite; 150ms fade in-out (reduced — мгновенно) |
| Поля | `05` §2.5 полный набор + eye-кнопка (default/hover/focus/pressed/aria-label меняется «Показать пароль»↔«Скрыть пароль») |
| Кнопки «Войти»/«Создать аккаунт» | `05` §2.1 + loading «Входим…»/«Создаём…» |
| Вердикт ошибки | default(нет)/error (инлайн, polite, с «что проверить»)/reduced-motion |
| Чип уже-вошёл | не показывается — страница сразу редиректит (§4.2) |

## 5. Сессия, чип пользователя, выход

### 5.1 Модель

`localStorage["vesmaro.authSession"] = { user, role, since }`
(role: `owner` | `member`; since — ISO-таймстамп). Отдельный префикс ключа —
не `stand-`: сессия — модельная сущность, а не настройка вида. Чтение —
общий hook в shell.js: на каждой странице Shell

1. прочитать сессию → `data-auth="anon|user"` на `<html>`;
2. отрисовать футер-статус (§1), топбар (§2.3), замки сайдбара (§2.2);
3. если страница гейт-раздела и сессии нет → заменить слот контента гейтом
   (§3) до первого paint контента (мигания контента быть не должно).

RU/EN: все новые строки — в словарь i18n парами (канон `07a` §7: паритет в
одном PR). Ключевые пары: «Войти/Sign in», «Регистрация/Sign up», «Выйти/
Sign out», «аноним/anonymous», «вы: X/you: X», «Раздел „X“ откроется после
входа/“X” opens after you sign in».

### 5.2 Чип пользователя (авторизованный топбар)

```
                                    ┌──────────────────────────┐
 (A abyss ▾)  ──────────────────►   │ вы: abyss · владелец     │
                                    │ вход: 2 ч назад          │
                                    │ ──────────────────────── │
                                    │ Профиль                  │
                                    │ Выйти                    │
                                    └──────────────────────────┘
```

- **Анатомия**: круг 24px `--color-iris-solid` с первой буквой имени
  (inverse-текст) + имя `--text-ui` + шеврон; цель ≥24×24, мобильный 44px.
  Кнопка с `aria-haspopup="menu"` / `aria-expanded`.
- **Меню** (`role="menu"`): заголовок-группа «вы: <имя> · <роль>» (роль
  человеческим словом: «владелец»), строка «вход: 2 ч назад» (интервал по
  `07a` §1.5), разделитель, пункты. **Профиль** — честная заглушка стенда
  (тост «Профиль — появится в продуктовой версии», паттерн
  `[data-demo-action]`). **Выйти** — действие §5.3.
- **Клавиатура**: ↑/↓ по пунктам, `Esc` закрывает и возвращает фокус на чип,
  клик вне — закрывает, фокус-трап внутри меню (канон оверлеев `03` §7).

### 5.3 Выход

- Выйти → сессия удалена → тост «Вы вышли из аккаунта» → если текущая страница
  гейт-раздела, редирект на Обзор; на публичной странице остаёмся (Обзор
  перерисовывается в анонимную сводку, топбар — в пару «Войти/Регистрация»).
- Confirm не нужен: выход обратим повторным входом (правило `05` §2.1 —
  confirm только для разрушающего).
- `auth.html` после выхода показывает форму входа (сессии нет — редирект-исход
  «уже вошёл» не срабатывает).

### 5.4 State-матрица чип-меню

| Компонент | Матрица |
| --- | --- |
| Чип | default/hover/focus-visible/open (aria-expanded=true, шеврон вверх)/disabled (не бывает) |
| Меню | open (150ms `--ease-enter`)/closing (`--ease-exit`)/reduced-motion (мгновенно)/focus-trap/Esc/click-outside |
| Пункты | default/hover/focus/active; Профиль — demo-action тост; Выйти — без loading (мгновенный честный исход) |
| Футер-статус и топбар после выхода | anonymous-вид без перезагрузки страницы (hook реагирует на событие сессии) |

Таблица видно/скрыто:

| Элемент Обзора | Аноним | Что именно |
| --- | --- | --- |
| Заголовок-статистика («ПАМЯТЬ ЖИВА · 12 483 записи · импульсов 37») | **виден** | агрегаты |

| Кнопка «Поделиться ▾» | **скрыта** | шарить анониму нечего — публичная сводка и есть общий вид |
| Строка-CTA | **добавлена** | «Статистика открыта всем. Войдите — увидите память целиком» + [Войти] + «Создать аккаунт» (ghost) |

- CTA-блок занимает слот живой ленты — композиция Обзора для анонима остаётся

- Состояние счётчиков: hover — курсор pointer, tooltip «Откроется после
  входа»; клик → гейт. Focus-ринг на счётчике как на цели (2.4.7).

| Переход | Значения |

## 8. WCAG 2.2 AA — именованные критерии

- **1.1.1 Non-text Content**: замок сайдбара — с текстовым tooltip и
  aria-label «Откроется после входа»; буква-аватар — декоративная
  (`aria-hidden`), имя текстом рядом.
- **1.4.1 Use of Color**: точка статуса, замки, вкладки — всегда с текстом или
  формой; вердикт ошибки — с префиксом «Ошибка:».
- **1.4.3 Contrast**: футер-строка muted 5.0:1 на well; вкладки/акценты —
  iris-bright 8.6:1 (dark) / 5.9:1 (light); пары `02` §4.
- **1.4.11 Non-text Contrast**: замок, ирис-подчёркивание вкладки, точка
  success (8.2:1) — ≥3:1 к подложке.
- **2.4.7 Focus Visible / 2.4.11 Focus Not Obscured**: ринг `--color-focus`
  на вкладках, полях, кнопках, чипе, пунктах меню; меню не перекрывает
  открытый ринг чипа (открытие меню уводит фокус внутрь).
- **2.5.8 Target Size**: eye-кнопка 24×24, пункты меню ≥36px, вкладки ≥36px,
  кнопки топбара 32px (мобильный 44px везде).
- **3.2.1 On Focus / 3.2.2 On Input**: вкладки не переключаются по фокусу;
  смена вкладки не отправляет форму; редиректы — только по явному действию.
- **3.3.1 Error Identification / 3.3.3 Error Suggestion**: вердикты auth —
  инлайн с «что проверить» (§4.2), не тостом и не цветом.
- **4.1.2 Name, Role, Value**: tablist/tab/tabpanel, menu/menuitem,
  disclosure-кнопки гейта с `aria-expanded`/`aria-controls`.
- **4.1.3 Status Messages**: тосты входа/выхода — `role="status"` polite;
  фокус на H1 гейта после перехода — announce polite.

## 9. Самокритика (проход 2)

- **Риск «SaaS-пейвола»**: гейт-экран с замками — самый заезженный паттерн.
  Отличие держится на трёх честностях: (1) гейт всегда отвечает «куда ещё
  посмотреть» — публичный Обзор назван и доступен, тупика нет; (2) никакого
  превью-блюра и счётчиков «осталось N дней»; (3) замок объясняет, что будет
  после входа, конкретикой раздела, а не «Premium». Проверка «сними бренд»:
  связка «публичная сводка + гейт с путём назад» опознаётся, но копирайт
  («Раздел „Память“ откроется после входа», «увидите память целиком») — из
  словаря колодца, не из шаблона подписок.
- **Риск двух правд о версии**: строка футера, подпись Галереи и auth/pair —
  один источник `STAND.version`; дубли в разметке запрещены §1.1. Версия
  «1.41.0» — пример брифа; источник истины номера — владелец/релизный процесс,
  спека фиксирует только канал доставки в UI.
- **Риск «анонимный Обзор = ободранный экран»**: композиция сохраняет
  двухзонность и живой заголовок-статистику; скрытые зоны отдают место строке
  сводки и CTA, а не пустоте. Счётчики кликабельны в гейты — цифры остаются
  «живыми» выходами, не декором.
- **Риск утечки через URL**: `?return=` хранит только путь, не содержимое;
  гейт по прямому URL с id сущности не рендерит данные (§2.2). Стенд не
  имитирует серверную авторизацию и говорит об этом честно (§4.2) —
  продуктовая проверка прав остаётся за сервером, это контракт, не вид.
- **Расхождение с брифом**: роль «владелец» не влезла в строку футера —
  перенесена в tooltip и меню чипа (§0, записано); поиск анонима скрыт, а не
  заблокирован (§0).

## 10. Открытые вопросы владельцу (≤3, с рекомендациями)

1. **Галерея — публичной?** Рекомендация: да. Витрина дизайн-системы не несёт
   содержимого памяти; публичность показывает стенд честнее. Если «нет» —
   переключается одной строкой конфига публичности (§2.1).
2. **Документы — публичными?** Рекомендация: да. Документация проектов обычно
   публична и это витрина работы агентов. Если «нет» — та же строка конфига.
3. **Регистрация в продукте**: только первый запуск создаёт владельца, дальше
   вход по приглашению? Рекомендация: да — для персонального борта открытая
   регистрация не нужна; вкладка «Регистрация» в UI тогда показывается только
   пока владельца нет (строка «Первый созданный аккаунт становится владельцем»
   это уже покрывает).
