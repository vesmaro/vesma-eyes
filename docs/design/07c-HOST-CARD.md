# 07c — Карточка «Жизнь хоста»

> Status: **v1.0, дизайн-лид, 2026-09-27**. Переработка правой панели
> «Карточка исполнителя» `/agents/hosts`: «стена полей + абзацы-дисклеймеры» →
> «сводка жизни + свернутое техническое дно». Словарь — `07a`; страница-реестр
> хостов описана в `07f` §3.3. Плотность созерцательная (сводка) с
> операционными вставками (списки событий).

---

## 1. Принцип: сводка жизни, не стена полей

Сегодняшняя карточка — форма из ~15 полей с четырьмя абзацами дисклеймеров.
Проблема не в данных, а в порядке: интерфейс отвечает «как отредактировать»,
а владелец спрашивает «что происходит и что мне сделать». Целевой порядок
чтения: **кто — чем занят — что было — что можно сделать — (детали)**.

Карточка остаётся дровером справа (≥480px, поверх реестра, `Esc` закрывает,
«Открыть полностью» — нет: карточка самодостаточна) — паттерн подглядывания
концепта §4.2.

```
┌────────────────────────────────────────────────────────────────┐
│ laptop-go-1                                    [×]             │
│ ● на связи · последний доклад 12 с назад                      │
│ без задач 3 ч                                                  │
│ ──────────────────────────────────────────────────────────────│
│ СЕЙЧАС                                                         │
│ ▸ задача «UI-10 проводник» · идёт · отчёт 6 мин назад  [→]     │
│ сессия zcode · открыта 41 мин          [Открыть в Коре]        │
│ ──────────────────────────────────────────────────────────────│
│ НЕДАВНО                                                        │
│ 14:02  доклад · агент отчитался (опрос)                        │
│ 12:40  отчёт задачи «UI-10»: «волна 1 закрыта»         [→]     │
│ 09:15  задача «UI-11» завершена                        [→]     │
│ ──────────────────────────────────────────────────────────────│
│ БЫСТРЫЕ ДЕЙСТВИЯ                                               │
│ [Дать задачу] [Сессии в Кору] [Проверить связь]                │
│ ──────────────────────────────────────────────────────────────│
│ УМЕНИЯ И РОЛИ                                                  │
│ Умения: пока не назначены — задачи хост не найдут.             │
│ [Назначить умения]                                             │
│ Роли: researcher, frontend            [+ Добавить роль]        │
│ Роли помогают подбирать задачи.                                │
│ ──────────────────────────────────────────────────────────────│
│ ▸ Технические детали                                           │
└────────────────────────────────────────────────────────────────┘
```

Правило: **всё, что сегодня абзацами — либо в «Технические детали», либо
одна строка-подсказка.** В основном слое ноль абзацев-дисклеймеров.

## 2. Шапка

- Имя — H2 (edit только по кнопке-карандашу, не инпут в лица шапки: сегодня
  инпут «Имя» — самое верхнее поле, что превращает сводку в форму).
- Статус-пилюля по lifecycle `07a` §4: точка + текст + возраст доклада.
- Вторая строка — занятость человеческим языком (правило двух фактов):
  «без задач 3 ч», «задач в очереди: 1», «выполняет задачу · пульс свежий».
- Возраст «0 мин» запрещён: «только что» (12 с назад / только что / N мин —
  формат относительного времени с tabular-nums).

---

## 3. Блок «Сейчас»

Три слота; пустой слот не рендерится (канон против дашификации):

1. **Активные задачи**: строка на assignment — заголовок задачи (без id),
   состояние («идёт», «ждёт старта 4 мин»), возраст последнего отчёта,
   клик → задача. Stagnation — warning-текст «в очереди 12 мин — исполнитель
   молчит» (честный возраст, спека агентов §3.1).
2. **Текущая сессия**: активная сессия харнеса — «сессия zcode · открыта
   41 мин» + [Открыть в Коре]. Клик ведёт на `/kora?host=<id>` с
   предфильтром — сквозной переход в мир сессий (`07d`).
3. **Покой**: если ничего — «Простаивает 12 минут» + primary **«Дать задачу»**
   (переход на задачи с предвыбором хоста). Покой — не стыдливый пустой блок,
   а явное состояние с действием.

Состояния блока: loading (скелетон 2 строк) / error (строка «Не прочиталось —
повторить») / empty-слоты не рендерятся; если блок целиком пуст (хост выключен) —
заменяется пояснением состояния из §6.

---

## 4. Блок «Недавно»

3–5 последних событий (доклады агента, отчёты задач, смены задач, включения/выключения):

```
14:02  агент доложился (опрос)          ← mono-время + текст
12:40  отчёт задачи «UI-10»: «волна 1 закрыта»   [Открыть →]
09:15  задача «UI-11» завершена — отчёт принят   [Открыть →]
```

- Каждая строка: время (mono tnum) + событие человеческим языком + переход,
  если есть куда. «Доложился (опрос)» — события-сердцебиения показываем один
  раз в хвосте, не заваливаем ленту (агрегат «доклады: 47 за день» —
  в «Технические детали»).
- Live: новые события всплывают сверху 240ms `--ease-enter`; reduced-motion —
  мгновенно. Максимум 5, «Показать все события» → Кора с фильтром хоста.
- Пусто (новый хост): «Тишина. Первые события появятся после первого доклада
  агента — обычно до 2 минут» + [Проверить связь].

---

## 5. Блок «Быстрые действия»

Три кнопки-действия (secondary, не три primary):

| Кнопка | Ведёт | Правило доступности |
| --- | --- | --- |
| «Дать задачу» | задачи, предвыбор хоста | disabled если хост выключен/отозван — tooltip почему |
| «Сессии в Кору» | `/kora?host=<id>` | всегда |
| «Проверить связь» | реальный опрос агента | loading-состояние «Проверяем…»; результат — toast «Ответил за 0,8 с» / «Не отвечает: …» |

Заголовок «Быстрые действия» — caps-лейбл `--text-caps`. Все три цели ≥24px,
на мобильном 44px.

## 6. Специальные состояния

### 6.1 «Выключен владельцем»

Шапка: пилюля «выключен владельцем» + строка **«Новые задачи не получает.
Доклады продолжаются — машина жива»**. Одна кнопка-действие в шапке: [Включить].
Отличия от отзыва — проговариваем строкой в блоке состояния, не абзацем:
- Выключен: связь остаётся, история на месте, вернуть — одной кнопкой.
- Отозван: секрет больше не действует, агент на машине остановлен/убран,
  вернуть можно только новым подключением.

### 6.2 «Отозван»

Карточка read-only: пилюля «отозван · N дней назад», блок состояния:
«Доступ отозван. Секрет агента больше не действует; на машине его сервис
остановлен.» Кнопки «Дать задачу»/«Проверить связь» скрыты (не disabled —
скрыты, т.к. бессмысленны; правило: скрываем, только когда действие
невозможно в принципе). Внизу одна кнопка: [Подключить заново] → мастер 07b
с префиллом имени.

### 6.3 «Ждёт одобрения» (между подключением и одобрением)

Отдельный вид карточки: блок «Сейчас» заменяется на approve-панель
(данные из provisioner-контракта §D): «зарегистрировался с IP 10.0.0.4 ·
через токен регистрации · отпечаток запомнен» + [Одобрить и включить] +
[Отклонить]. Блок «Обнаружено на хосте» (discovery): список найденных харнесов
с кнопкой «Принять» (автозаполнение умений — серверное поле
`capabilities_source: auto-discovered`, метка «найдено агентом»). Пояснение
одной строкой: «Проверьте: тот ли это IP, где стоит машина».

## 7. Блок «Умения и роли»

Один блок вместо двух разрозненных полей прод (замена дубля
«Возможности: возможности не заявлены»):

```
УМЕНИЯ И РОЛИ
Умения: пока не назначены — задачи хост не найдут. [Назначить умения]
  подсказка (tooltip/строка): «Умения — что хосту можно запускать.
  Их назначаете вы; хост не может добавить их сам.»
Роли: researcher · frontend              [+ Добавить роль]
  подсказка: «Роли помогают подбирать задачи: например, researcher»
```

- Умения — чипы (анатомия `05` §2.2); добавление — комбобокс словаря сервера;
  чипы из discovery помечены точкой-«найдено агентом» + tooltip «найдено
  агентом на машине — вы принимали при одобрении».
- Роли — input со словарём специалистов + [Добавить роль]; добавление —
  toast «Роль добавлена» (канон toast `05` §3).
- Строка «изменений нет» прод заменяется: сохранение — только по кнопке
  [Сохранить] при наличии правок; кнопка рендерится только тогда
  (disabled-кнопка без причины — блокер-канон).

## 8. «Технические детали» (свернутое дно)

Сворачиваемый блок (анатомия `07a` §6). Содержимое — всё, что было абзацами:

| Группа | Строки |
| --- | --- |
| Идентификация | id хоста (mono, копировать), зарегистрирован по токену · 2026-09-27, IP первого входа, отпечаток машины (SHA256:…, обрезан, «показать целиком») |
| Софт | версия агента v0.1.1 · версия харнеса · транспорт «докладывается из локальной сети» (или «через VPN») |
| Харнес | «работает через zcode · менять нельзя без перерегистрации» (одна строка) + полный абзац про allowlist и рассинхронизацию |
| Связь | «агент сам докладывается каждые ~2 мин — сервер его не дёргает» + интервал из конфига + история присутствия (last-seen trail) |
| Токены | «секрет показывается один раз при регистрации. Потеряли — выключите хост и подключите заново» |
| Доклады | 47 докладов за сегодня, интервал, средняя задержка (mono) |
| Опасная зона | [Выключить] / [Отозвать доступ] / [Удалить] — каждый с confirm-модалом, называющим последствие и число («Отозвать laptop-go-1? Секрет перестанет действовать, агент на машине остановится. Вернуть можно только новым подключением») |

Раскрытие: 240ms `--ease-enter`, состояние персистентно per-хост; шеврон —
кнопка ≥24px; внутри — таблица определений `--text-data` (лейбл muted, значение primary).

## 9. State-матрица карточки

| Компонент | Матрица |
| --- | --- |
| Дровер | open(240ms enter)/closing(exit)/Esc/клик мимо/focus-trap/возврат фокуса в строку реестра |
| Шапка | loading(скелетон)/default/выключен/отозван/ждёт одобрения/error (данные не прочитались — «Повторить») |
| Блок «Сейчас» | loading/слоты/покой(«Дать задачу»)/error-строки |
| Блок «Недавно» | loading/empty(«Тишина…»)/live-всплытие/error |
| Кнопки действий | `05` §2.1 + disabled с пояснением + loading «Проверяем…» |
| Умения/роли | чипы `05` §2.2 + добавление/удаление + saving(toast)/error(toast) |
| Тех. детали | collapsed/expanded(персистентно)/focus на шевроне |
| Stale (SSE-разрыв) | строка «данные на HH:MM» вверху карточки (канон спеки агентов §3.2) |

A11y: дровер — `role="dialog"` `aria-modal="true"` с заголовком-именем хоста;
порядок фокуса: шапка → Сейчас → Недавно → Действия → Умения → детали;
`aria-live="polite"` только для терминальных переходов статуса. Цвет статуса
дублируется текстом всегда (WCAG 1.4.1). `prefers-reduced-motion`: раскрытия
мгновенные, всплытия — без движения.
