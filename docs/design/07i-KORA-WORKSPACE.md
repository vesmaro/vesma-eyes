# 07i — Кора: рабочая область (док)

> Status: **v1.0, дизайн-лид, 2026-09-27**. Директива владельца (вердикт по v3,
> 2026-09-27): правая панель при выборе сессии нужна, но как
> **информационно-конфигурационная**; работать — в **док-панели по центру внизу**,
> постоянной, со сворачиванием; при развороте дока список сессий переезжает в
> правую панель. База: `07d` (список, строка, свиток, покрытие — переносятся
> без изменений), `07a` (словарь), `05` (state-матрицы), `06` (motion),
> `02` (токены). Честность руления: срез 3 — ADR 0019, контракт
> `docs/kora/openapi.yaml` (заморожен). Кода не содержит: реализация —
> `@gcw-senior-frontend-developer`.
>
> **Supersede v5 (2026-09-28):** док-модель упразднена — рабочая зона всегда
> развёрнута в центре, сессии уехали в правую панель, низ стал «Пультом» —

## 0. Что меняется против 07d

| В 07d | Стало (07i) |
| --- | --- |
| Клик по строке → транскрипт-дровер справа (§3) | клик → состояние (б): инфо-карточка справа + тонкая полоса дока внизу; «Развернуть» → (в): контент в доке |
| Транскрипт живёт в правой панели | транскрипт живёт в доке; правая панель — инфо + переключение |
| «Открыть полностью» → роут `/kora/:sessionId` | сохраняется: `/kora/:sessionId` — полноэкранный рабочий режим (§7) |
| Список сессий всегда в центре | в рабочем режиме (в) список переезжает в правую панель |
| §1–2 (список/строка), §4 (пустые), §5 (покрытие), §6 (сводка) | без изменений |
| Свиток-канон §3 (Lora, coverage, состояния) | переносится в док дословно |

Метафора: «док» — то же паттерн-семейство, что док рабочего стола (`04` §6):
постоянная поверхность по центру внизу, которая вырастает в рабочую. Это
единственная смелая форма страницы Коры — всё остальное тихо (канон
«смелость в одном месте»).

## 1. Принцип: правая панель = инфо, док = работа

Пользователь спрашивает у правой панели «что это и что здесь можно
посмотреть/настроить», у дока — «покажи содержимое, с которым я работаю».
Корень претензии владельца — смешение ролей: панель делала вид работы
(транскрипт в узкой колонке), но геометрически не была рабочей поверхностью.
Таблица соответствия — §6.

## 2. Три состояния Коры

Машина состояний: (а) —(выбор строки)→ (б) —(«Развернуть»/`koraDock=open`)→
(в) —(«Свернуть»/Esc)→ (б) —(«Снять выбор»/Esc)→ (а).

### 2.1 (а) Сессия не выбрана

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Кора · сессии хостов      [Фильтр: ▾ Все хосты]  [Проверить связь]           │
│ 2 хоста на связи · 1 сессия идёт · за 24 ч: 4                                │
│ ┌─ СЕССИИ ──────────────────────────────────────────────────────────────────┐│
│ │ ● laptop-go-1 · zcode    идёт · открыта 41 мин · активность 2 мин назад  →││
│ │ ○ laptop-go-1 · zcode    вчера 18:04–19:22 · 1 ч 18 мин                  →││
│ └───────────────────────────────────────────────────────────────────────────┘│
│ ▸ Покрытие                                                                   │
│                ╭─ РАБОЧАЯ ОБЛАСТЬ ──────────────────────────────╮            │
│                │ Рабочая область — выберите сессию              │            │
│                ╰────────────────────────────────────────────────╯            │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Центр: список сессий (`07d` §1–2) + «Покрытие» внизу — без изменений.
- Док: постоянная полоса 48px по центру внизу — floating, `--color-bg-well`,
  верхние углы `--radius-lg`, `--shadow-float`, функциональный край
  `--color-border`. Содержимое: caps-лейбл «РАБОЧАЯ ОБЛАСТЬ» (`--text-caps`,
  `--color-text-muted`) + строка-приглашение «Рабочая область — выберите
  сессию» (`--text-ui`, `--color-text-secondary`).
- Полоса **некликабельна** — это приглашение, а не тупик: путь к действию даёт
  список над ней. Варианты копирайта при нулевых хостах/оффлайне — §9.

### 2.2 (б) Сессия выбрана, док свёрнут

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Кора · сессии хостов      [Фильтр: ▾ Все хосты]  [Проверить связь]           │
│ ┌─ СЕССИИ ──────────────────────────────────┐ ┌─ zcode · laptop-go-1  [×] ─┐│
│ │ ● laptop-go-1 · zcode   идёт · 41 мин   → │ │ ● идёт · открыта 41 мин    ││
│ │ ○ laptop-go-1 · zcode   вчера 18:04     → │ │ ПОКРЫТИЕ ЭТОЙ СЕССИИ:      ││
│ │ ○ …                                       │ │ полный транскрипт (zcode)  ││
│ └────────────────────────────────────────────┘ │ ▸ Технические детали       ││
│ ▸ Покрытие                                     │ [Развернуть рабочую обл.]  ││
│                                                │ Открыть полностью →        ││
│   ╭─ ● идёт · zcode · laptop-go-1 ── [Развернуть ⌄] ─────────────╮           │
│   ╰───────────────────────────────────────────────────────────────╯          │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Центр: список; выбранная строка — selected-вид (`05` §2.3).
- Правая панель — **ИНФО-карточка сессии** (дровер ≥560px, как `07d`; ≥1024px —
  колонка): шапка (харнес · хост, [×] снять выбор), пилюля статуса (`07d` §2),
  честная coverage-строка (`07d` §3: «полный транскрипт» / «видно только
  начало…» / «этот терминал пока не сканируем»), «▸ Технические детали»
  (`07a` §6: id сессии, источник-сканер, границы транскрипта, «управление:
  срез 3 (ADR 0019)»), действия: **[Развернуть рабочую область]** (primary) и
  ссылка «Открыть полностью →» (`/kora/:sessionId`). **Транскрипта здесь нет** —
  чтение переезжает в док.
- Полоса дока: [пилюля статуса] [имя сессии «zcode · laptop-go-1»] …
  [Развернуть ⌄] — кнопка ≥44×44, `aria-expanded="false"`,
  `aria-controls="kora-dock"`.

### 2.3 (в) Док развёрнут — рабочий режим

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Кора · сессии хостов   [Фильтр ▾] [Проверить связь]          ▸ Покрытие      │
├──────────────────────────────────────────────────┬───────────────────────────┤
│  ╭─ zcode · laptop-go-1 ── ● идёт ────────────────────────────────────╮      │
│  │ [Следить за хвостом ✓] [⌕ Найти в сессии…]            [Свернуть ⌃] │      │
│  │ ─────────────────────────────────────────────────────────────────│      │
│  │ (транскрипт-свиток: Lora, --color-scroll-bg, ≤72ch)              │      │
│  │ 18:04  вы: поправь тесты в tokens.test.ts                 [⧉]   │      │
│  │ 18:06  zcode: разобрал 3 падения…                         [⧉]   │      │
│  │ ─ Управлять сессией отсюда пока нельзя — только читать. Это в   ─│      │
│  │ [ Ввод появится позже… ]  (disabled, tooltip: срез 3)            │      │
│  ╰───────────────────────────────────────────────────────────────────╯      │
│                                                  ┌─ СЕССИИ · переключение ──┤
│                                                  │ ● laptop-go-1 · сейчас   │
│                                                  │ ○ laptop-go-1 · вчера    │
│                                                  │ ▸ О выбранной сессии     │
│                                                  │ [Свернуть рабочую обл.]  │
└──────────────────────────────────────────────────────────────────────────────┘
```

- Док поднимается по центру до **~55vh** (`clamp(320px, 55vh, доступная
  высота)`): шапка дока (см. §3) → тело: транскрипт-свиток (`07d` §3 дословно:
  Lora `--font-scroll`, `--color-scroll-bg`, `--text-md`,
  `--leading-relaxed`, measure ≤72ch, mono-времена, живая догрузка снизу,
  coverage-пометка первой строкой, частичное покрытие «— на этом данные
  заканчиваются») → подвал честности (§5).
- Инструменты чтения — реальные (§4): toggle «Следить за хвостом», «⌕ Найти
  в сессии…», копирование реплики.
- **Список сессий переезжает в правую панель**: заголовок «Сессии ·
  переключение», компактный список (точка статуса + хост · харнес + время,
  `--text-data`), активная строка — selected-вид; **клик меняет контент дока,
  не сворачивая его**. Ниже — «▸ О выбранной сессии» (свёрнутый блок с
  содержимым инфо-карточки (б): coverage, тех. детали, действия). Внизу —
  **[Свернуть рабочую область]** (secondary, ≥44px) — возвращает (б) как было.
- Центр над доком: шапка страницы + «Покрытие» (карточка `07d` §5 остаётся в
  потоке над доком). Свободной ямы нет, док прижат к низу.

## 3. Полоса и шапка дока — один элемент

Свёрнутая полоса и шапка развёрнутого дока — **один header-элемент, меняющий
состав** (имя + пилюля + «Развернуть» → имя H2 + пилюля + coverage-строка +
инструменты + «Свернуть»), а не два. Это снимает дублирование статуса и
дёрганье: высота 48px фиксирована, содержимое с ellipsis, смена пилюли — тинт
80ms (`--duration-instant`) без layout shift. Полоса никогда не анимирует свою
высоту сама — только по команде «Развернуть»/«Свернуть».

## 4. Инструменты чтения — реальные (в стенде работают)

| Инструмент | Поведение | Честность |
| --- | --- | --- |
| «Следить за хвостом» | toggle, по умолчанию ВКЛ для «идёт»; ручной скролл вверх → авто-ВЫКЛ + плавающая [Вернуться к хвосту ↓] (появление 150ms `--ease-enter`); повторное включение — прокрутка к хвосту | для «завершена/прервана» toggle скрыт (следить не за чем — правило скрытия из `07c` §6.2) |
| Копировать реплику | hover/focus реплики → кнопка ⧉ ≥24px (мобильный 44px); клик → точный текст с таймстемпом в буфер + toast «Реплика скопирована»; отказ буфера → toast «Не скопировалось — выделите текст вручную» | копируется содержимое реплики, не «красивый» пересказ |
| «Найти в сессии…» | фильтр реплик: совпадения подсвечены (фон-тинт + жирный, не цветом одним — 1.4.1), счётчик «Найдено: 4» (`polite`), Esc — очистить и вернуть все реплики | реальный фильтр стенда; пусто → «Ничего. В этой сессии таких реплик нет» |

Транскрипт рендерится окнами (виртуализация): tab-стопы копирования есть только
у видимых реплик; длинную сессию сужает поиск. Клавиатура: реплики — текст в
`role="log"` (нативное выделение работает), кнопки ⧉ — в tab-порядке.

## 5. Честность: руление — срез 3

- Строка над подвалом дока (словарная, `07a` §3.5): **«Управлять сессией
  отсюда пока нельзя — только читать. Это в планах»**.
- Поле-заглушка: disabled input высотой 44px, placeholder «Ввод появится
  позже», **tooltip: «Управление сессией появится со срезом 3 — сейчас только
  чтение»** (идентификатор среза — в tooltip/деталях: `07a` §1.4; директива
  владельца о честной строке со срезом выполнена, основной слой остаётся
  чистым по словарю). Поле не принимает текст и не фокусируется — честная
  мёртвая зона с объяснением, никакой фейковой консоли.
- Внутренняя привязка: руление — срез 3 (ADR 0019), контракт
  `docs/kora/openapi.yaml` заморожен; строка «управление: срез 3 (ADR 0019)»
  живёт в «Технических деталях».
- Слово «скоро» запрещено (`07d` §3) — только «Это в планах».

## 6. Разделение ролей: что где живёт

| Вопрос пользователя | Где ответ | Состояния |
| --- | --- | --- |
| «Что за сессия: кто, где, насколько полные данные» | правая панель: шапка + coverage-строка | (б) развёрнуто; (в) свёрнуто под списком («▸ О выбранной сессии») |
| «Детали и действия (id, ссылка, снять выбор)» | правая панель: тех. детали + действия | (б) развёрнуто; (в) свёрнуто |
| «Переключить сессию» | центр (а/б) → правая панель, список (в) | клик в (в) меняет док, не сворачивая |
| «Читать и работать с содержимым» | док | (в) развёрнут |
| «Фильтр, сводка хостов, Проверить связь» | шапка страницы | всюду, не меняется |
| «Что видно по харнесам» | «Покрытие» (`07d` §5) | внизу центра (а/б); над доком (в) |

Правило: ни один вопрос не отвечает в двух местах (нет дублей); при развороте
ничего не пропадает — инфо сворачивается в панель, список переезжает.

## 7. Поведение, персистентность, клавиатура

- **Персист**: `vesmaro.koraDock = "auto" | "open"` (localStorage). `auto` —
  выбор сессии оставляет док свёрнутым (б); `open` — выбор сессии сам
  разворачивает док (в). Меняется только явным действием:
  [Развернуть]/[Свернуть]/Esc. Глубокие ссылки pref не трогают:
  `/kora/:sessionId` — полноэкранный рабочий режим (док как главный контент);
  `/kora?session=<id>` — выбор без разворота.
- **Esc-лестница** (стек `03` §7): (в) → свернуть в (б), фокус → кнопка
  «Развернуть»; (б) → снять выбор в (а), фокус → строка сессии; (а) → ничего.
- **Клавиатурный путь полный**: строка списка — кнопка (Enter = выбрать);
  полоса: Tab → [Развернуть]; док: Tab — инструменты → транскрипт
  (`role="log"`) → подвал; правая панель: список → «▸ О сессии» → [Свернуть].
  Ловушек нет (WCAG 2.1.2).
- **Фокус**: при развороте переносится в заголовок дока (H2, `tabindex="-1"`);
  при сворачивании — обратно на кнопку полосы. При смене сессии в (в) фокус
  остаётся на месте пользователя, смена объявляется `polite`.
- **Scroll-история**: Map⟨sessionId, {offset, followTail}⟩ в памяти страницы;
  возврат к сессии восстанавливает позицию; сессиям с включённым хвостом —
  восстановление на хвост. Между визитами позиция не хранится: журнал живой,
  старая позиция врёт. Активная строка правого списка — `scrollIntoView
  (nearest)` при переключении.

## 8. Motion (канон `06`)

| Что | Как |
| --- | --- |
| Разворот дока | высота 48px → 55vh, `--duration-normal` (250ms, окно 240–400) + `--ease-enter`; директивные 240ms — нижняя граница окна токена, вне лестницы значений не вводим (`02` §1) |
| Сворачивание | `--duration-normal` + `--ease-exit` (парность вход/выход) |
| Полоса не дёргается | высота фиксирована; live-обновления пилюли — тинт `--duration-instant`, без геометрии |
| Переезд списка центр → право | центральный: opacity → 0, 150ms `--duration-fast` + `--ease-exit`; правый: каскад stagger ≤8 (`06` §3); обратно зеркально; без FLIP-перелётов |
| Смена сессии в доке | crossfade 150ms; высота дока не прыгает; loading — скелетон 2 абзацев |
| «Вернуться к хвосту» | появление/уход 150ms `--ease-enter`/`--ease-exit`, без пружин |
| reduced-motion | раскрытия и каскады мгновенные (токены `02` §7), прокрутка к хвосту — jump, «Вернуться к хвосту» — появление ≤80ms opacity |

## 9. State-матрица

| Компонент | Матрица |
| --- | --- |
| Полоса (а) | приглашение / хостов нет («Хостов ещё нет — сессиям неоткуда браться», `07d` §4) / хосты не на связи («Хосты не на связи — сессии не обновляются») / некликабельна: hover/focus нет |
| Полоса (б) | default / live-обновление пилюли (пульс точки только на реальное событие, `06` §5) / stale (SSE-разрыв: warning-точка + «данные на HH:MM») / focus на [Развернуть] |
| Док (в) | loading (скелетон) / live (идёт: follow-tail, догрузка снизу 240ms enter) / завершена (follow-tail скрыт, подпись «Сессия завершена · 18:04–19:22») / прервана (warning-подпись, `07d` §2) / пустая («В этой сессии пока нет реплик: агент начал работу и ещё не говорил. Первая появится с первым ходом — обычно до 2 минут») / частичное покрытие («Показать, что есть» + явный конец данных) / error («Транскрипт не прочитался» + [Повторить]) / stale («данные на HH:MM» вверху) / reduced-motion |
| Заглушка ввода | disabled всегда + tooltip; курсор not-allowed; из tab-порядка исключена |
| Follow-tail | on (`aria-pressed="true"`) / auto-off при скролле вверх + [Вернуться к хвосту] / скрыт на терминальных сессиях |
| Поиск в сессии | default / typing (debounce 300) / results (счётчик + подсветка) / empty («Ничего…») / Esc-очистка |
| Инфо-карточка (б) | loading/default/выключен-хост/error — наследует `07d` §7 (инфо-часть) |
| Переключатель (в) | loading (скелетон 3 строк) / active-строка (selected-вид) / все хосты офлайн («Хосты не на связи — новые реплики не поступят, пока агенты не доложатся» + [Проверить связь]) / error («Список не прочитался» + [Повторить]) / stale |
| Кнопки разворота/сворачивания | ≥44×44; default/hover/focus-visible/active; `aria-expanded` + `aria-controls` |

A11y: док — `role="region"` `aria-label="Рабочая область сессии"` с H2;
кнопка разворота — disclosure-семантика (`aria-expanded`/`aria-controls`),
«Следить за хвостом» — независимый toggle (`aria-pressed`); директива
«aria-press» покрыта: состояние каждого контрола объявлено для скринридера,
механика — по типу контрола (ARIA APG: disclosure → expanded, toggle →
pressed). `aria-live`: смена режима дока и смена сессии — `polite`; новые
реплики — `off` (канон `07d`). Цвет статуса всегда дублируется текстом
(1.4.1). Reflow 320px: строки списков — карточный вид <768px (`07d` §7).

## 10. Мобильный вариант

- ≥1024px: правая панель — колонка 320–360px; док центрируется в оставшейся
  ширине.
- 768–1024px: правая панель → дровер поверх (в (в) — кнопка «Сессии» в шапке
  дока; инфо-карточка в (б) — дровер, как `07d`); док на всю ширину контента.
- <768px: док — bottom sheet на всю ширину (верхние углы `--radius-lg`;
  ручки-граба нет: сворачивание только кнопками, ≥44px); высоты те же;
  свиток ≤72ch сохраняется; все цели 44px (страница и есть тач-сценарий).

## 11. WCAG 2.2 AA — именованные критерии

- **1.4.3 Contrast**: пары `02` §4; worst-case — caps-лейбл полосы
  `--color-text-muted` на well (5.0:1).
- **1.4.11 Non-text Contrast**: край дока `--color-border` (≥3:1 на well),
  точки пилюль, подсветка совпадений.
- **2.4.7 / 2.4.11 Focus Visible / Focus Not Obscured**: разворот переносит
  фокус внутрь дока — под поверхностью не остаётся сфокусированного; на
  плавающей полосе offset ринга 4px.
- **2.5.8 Target Size**: полосные кнопки ≥44×44; инструменты ≥24 (44 мобильный).
- **2.1.2 No Keyboard Trap**: Esc-лестница §7.
- **4.1.2 Name, Role, Value**: `aria-expanded`/`aria-controls`/`aria-pressed`.
- **4.1.3 Status Messages**: смена режима дока и сессии — `polite`.
- **1.4.1 Use of Color**: статус — точка + текст всегда; подсветка поиска —
  фон + вес.

## 12. Самокритика (проход 2)

- **Проверка «сними бренд»**: полоса→рабочая область — паттерн IDE; данный
  вариант опознаётся по сочетанию «фиксированная полоса-приглашение + честная
  disabled-заглушка вместо фейковой консоли + переезд списка без
  анимационного цирка + свиток-типографика в доке». Фейковая рабочая консоль —
  главное клише этого паттерна; здесь вместо неё — заглушка со срезом в
  tooltip: это и есть смелое место страницы.
- **Риск «потерянного списка»**: пользователь в (в) может не заметить переезд.
  Митигация: активная строка выделена; при первом развороте — одноразовая
  `polite`-подсказка «Список сессий переехал в правую панель» (персист в
  сессии); [Свернуть рабочую область] возвращает всё как было.
- **Риск tab-взрыва транскрипта**: окна рендера ограничивают tab-стопы
  видимыми репликами; поиск сужает набор. Альтернатива «только нативное
  выделение» отвергнута — теряется тач-сценарий копирования.
- **Риск дёрганья живой полосы**: header один, высота фиксирована, обновления —
  тинты, не геометрия; проверяется ревью по матрице §9.
- **Токен-дисциплина против директивы**: 240ms раскрытия округлены до
  `--duration-normal` (250ms, окно 240–400) — вводить магическое значение ради
  −10ms нельзя; 55vh — layout-значение из директивы, не motion/цвет, оставлено
  как есть.
- **i18n**: все новые строки — ru/en одним PR (канон `07-INTEGRATION` §3).
