## 1. Принцип: одна страница-сводка, жив ли каждый блок

Формат каждого блока одинаковый — «жив/не жив + когда обновлено + клик ведёт
в профильный раздел». Никаких графиков ради графиков (анти-дашификация
концепта §2.4), никаких 501-простыней: если источник данных не отдаёт,
блок **не рендерится**, а его отсутствие компенсируется сводкой по соседним
блокам (ни один блок не заменяется мёртвым сообщением об ошибке).

## 2. Состав блоков (только реально существующие данные)

| Блок | Источник (существует сегодня) | Что показываем |
| --- | --- | --- |
| Хранилища | тот же, что питает «Обзор» (здоровье 4/4, seal-vault деградация) | строка на хранилище: точка + «жив / с оговорками / не отвечает» + возраст ответа; деградация — словами, не только цветом |
| Сервер | SSE-канал топбара + версия борда (уже показывается на Обзоре) | «связь живая · события приходят N с назад» + версия |
| Хосты | реестр executors (живой) | пилюли и формулировки `07a` §4, счётчик активных задач |
| Память | счётчики Обзора | записи/теги/импульсы за час/возраст последней записи (tabular-nums) |
| Задачи | счётчики канбана | идёт/в очереди/ждёт валидации/завершено за сегодня |
| Последние события | живая лента (SSE) | 5 строк: время + кто + что; каждая кликабельна, если есть куда |

Каждая строка — ссылка в профильный раздел (Хранилища/Хосты/Пульс/Канбан/Кора).
Заголовок каждого блока — caps-лейбл + кнопка-ссылка «Открыть …» справа.

## 3. Лексика живости

Единый словарь живости (цвета — `02-TOKENS` §4, всегда с текстом):

| Состояние | Формулировка |
| --- | --- |
| Жив | «жив · отвечает N с назад» |
| С оговорками | «с оговорками» + одно предложение человеческим языком («записи идут, часть запросов медленнее обычного») |
| Не отвечает | «не отвечает · последняя связь N мин назад» + [Проверить] |
| Данные задерживаются (SSE) | строка сверху: «данные на HH:MM — переподключаемся» (канон `04` §1 лента error) |

Возраст обновления страницы — в подзаголовке: «обновлено только что / N мин
назад»; если SSE разорван — предупреждение вверху вместо «только что».

## 4. Что запрещено на странице

- EN-абзацы технических ошибок (`BoardAdapter.metrics: the board merge-API…`) —
  никогда.
- Ссылки на ADR в основном слое — запрещены (`07a` §6).
- Формулировки «недоступно в board-режиме», «501», «merge-API» — из основного
  слоя удалены. Если однажды какой-то источник реально не отдаёт данные:
  блок не рендерится; в самом низу страницы — свёрнутая строка «Технические
  детали» с одной строкой: «Метрики исполнения пока не отдаются сервером —
  раздел соберётся, когда появятся» (без кодов и протоколов).
- Счётчики без перехода (число ради числа — дашификация).

## 5. Пустые и особые состояния

| Ситуация | Формулировка | Действие |
| --- | --- | --- |
| Блок-источник не отдаёт данных | блок не рендерится (не пустышка) | — |
| Все хранилища живы | строка-резюме над списком: «Всё живо — 4 из 4» (кратко для взгляда) | — |
| Деградация (seal-vault) | строка хранилища «с оговорками» + пояснение; блок подсвечен warning-точкой только у строки | клик → Хранилища |
| SSE разорван | баннер сверху: «Данные задерживаются — переподключаемся…» + пилюля топбара синхронна | авто/«Переподключить» |
| Хостов 0 | блок Хосты рендерится с приглашением: «Хостов ещё нет» + [Подключить хост] | → мастер 07b |
| loading | скелетоны по блокам (независимо: один блок может загрузиться раньше другого) | — |

## 6. State-матрица и a11y

| Компонент | Матрица |
| --- | --- |
| Строка хранилища/хоста | default/hover/focus/клик(переход)/stale-возраст/error |
| Резюме-счётчики | default/hover/фокус/клик к фильтру |
| Лента последних событий | live-всплытие 240ms / reduced-motion мгновенно / empty «Пока тихо» |
| Страница | loading(скелетоны)/live/stale(SSE разрыв)/error-блочная изоляция |

- Заголовок страницы — H1 с `tabindex="-1"`; фокус переносится на него при
  переходе (канон `03` §8). Обновления возрастов — без анимации (цифры меняются
  на месте, канон концепта §5.3).
- «С оговорками» и «не отвечает» — текст обязателен, точка — дублирует
  (WCAG 1.4.1); все пары контраста — из `02-TOKENS` §4 (AA везде).
- Цели ≥24×24, мобильный 44px; блоки складываются в одну колонку <768px
  без горизонтального скролла (WCAG 1.4.10).
