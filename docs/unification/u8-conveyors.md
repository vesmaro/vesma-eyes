# U8 «v12-UX-потоки» — инвентарь v12-паттернов и контраст конвейеров

> Status: v1.0, 2026-10-09 (волна U8, ветка feat/u8-v12-ux-flows).
> Источники: v12-стенд `wt/wow-v12/design/stand/{connect,tasks,hosts,agents}.html`
> (read-only), карточка U8-v12-ux-flows, движок main. Судьба каждого паттерна:
> ПЕРЕНЕСЕНО (срез)/НЕ ПЕРЕНОСИМ (почему)/ЧАСТИЧНО (что осталось). Красная линия
> волны: шаг конвейера = реальное состояние API-операции; фиктивные шаги и
> таймерные прогресс-бары = блокер. «Одна реализация на понятие» соблюдена китом:
> `components/conveyor/` (StepRail + conveyorStorage + useStepHeadingFocus) —
> единственные рельса, черновик и фокус-шаг всех трёх потоков.

## 2. Контраст конвейеров (WCAG 2.2 AA)

Ноль новых hex: все пары шагов — существующие семантические токены, уже
измеренные в `docs/design/02-TOKENS.md §4` (обе темы). Посадки U8:

| Поверхность | Пара | Токены | Расчёт |
|---|---|---|---|
| Рельса, текущий шаг | текст/фон | `--iris-bright` на `--iris`/10 + `border-iris-bright/60` | пара iris-bright/тёмный фон — §4 (акцентный текст ≥4.5 AA) |
| Рельса, пройденный шаг | текст/фон | `--foreground-secondary` на well | §4 secondary text |
| Рельса, впереди | текст/фон | `--foreground-muted` на well (не интерактивный вид — курсор запрещён) | §4 tertiary/muted |
| Баннер черновика | текст/фон/край | `--foreground-secondary`, `bg-well`, `border-border-subtle` | §4 (край non-text ≥3 — decor-слой двойной системы границ) |
| Заметка «закрытие не отменяет» | текст/фон | `--foreground-muted` на surface | §4 tertiary AA-фикс |
| Ошибка шага («нужен специалист») | текст/фон | `--error` на well + `aria-invalid` + `role=alert` | §4 error |
| Radio-cards «Кому» | текст/фон | `--foreground` + secondary-строка обещания; disabled = opacity-токен | §4 |
| Вспышка строки/карточки | кромка | `agents-presence-online` (impulse ≤0.18, success-токен) | §6 Motion + §4 |

Клавиатурный путь всех трёх конвейеров: рельса — нативные кнопки (Tab/Enter),
возврат по пройденным шагам, фокус после смены шага уходит на заголовок панели
(`useStepHeadingFocus`, tabindex=-1 — канон connect.html); radio-cards —
нативные fieldset/radio; диалоги — Radix (Esc/ловушка фокуса/возврат фокуса).

## 3. Гейт честности

`npm run honesty` расширен с 13 до **15** проверок — негативные контролы
декоративного прогресса в потоках U8: тихая шина + открытый конвейер → два
кадра через ≥5.6с попиксельно идентичны (таймерный бар был бы виден):

- **14. connect-silent** — `/agents/harnesses?connect=1`: рельса + карточка
  подключения (шаги движутся только реальными состояниями provision-задачи);
- **15. wizard-silent** — `/tasks/list?wizard=1`: мастер задачи (правило одного
  честного ретейка tasks-silent: ролловер минутного поля за диалогом — старение
  данных, не движение; устойчивый диффер краснит).
