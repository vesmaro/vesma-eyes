## Зачем этот файл

Спеки 07b/07c писались до выхода Go-агента 0.6.0 и в трёх местах обещают
пользователю механику, которой нет в протоколе, либо называют устаревшие
константы. Спеки живут в ветке-эталоне `experiment/design-neuro-v1`
(`design/docs/07b-CONNECT-MASTER.md`, `design/docs/07c-HOST-CARD.md`) и
по директиве владельца 2026-09-29 этой ветки не касаемся. Этот файл —
список правок, которые обязаны войти в текст спеков при переносе И5 в
main, чтобы перенос не закрепил ложные обещания.

## Как применять

- Правило одно: строка «Стало» заменяет строку «Было» в переносимом
  тексте спеки; всё, что не перечислено здесь, переносится как есть.
- Каждая эрратума самодостаточна: место, цитата, причина, готовая
  замена. Сверка источников — в конце файла.
- Эрратумы не меняют дизайн-решений (композиция, состояния, словарь) —
  только факты о механике связи с агентом.

## Э1 — «Проверить связь» не опрашивает агента (07c §5)

**Где.** 07c §5, таблица «Быстрые действия», строка кнопки; те же кнопки
в 07c §4 (пустое состояние ленты) и 07b §5.2/§5.3 (мастер подключения).

**Было (неверно).**

| Кнопка | Ведёт | Правило доступности |
| --- | --- | --- |
| «Проверить связь» | реальный опрос агента | loading-состояние «Проверяем…»; результат — toast «Ответил за 0,8 с» / «Не отвечает: …» |

**Почему неверно.** Агент исходящий-only: ноль входящих портов, борд не
имеет канала до агента и не может его «опросить» (ADR 0009 §9; PROTOCOL
§6 S3 — regression-blocking инвариант; §4 — «NO agent health endpoint»).
«Ответил за 0,8 с» — обещание пинга, которого архитектурально не
существует. Честная механика уже в проде с волны AGW-6 A: «Обновить
пульс» — refetch реестра исполнителей (инвалидация react-query-семейства
executors), вердикт — возраст последнего ответа агента против серверных
порогов присутствия, возраст дотикает общий 1 Гц тикер; постоянный
дисклеймер «сервер не дёргает агента».

**Стало (готовая замена).**

| Кнопка | Ведёт | Правило доступности |
| --- | --- | --- |
| «Обновить пульс» | перечитать реестр (борд не пингует агента) | verdict «отвечал N назад» по `last_seen` из реестра, пороги серверные; 1 Гц тикер обновляет возраст; дисклеймер «сервер не дёргает агента — агент на связи, если сам недавно докладывался» |

Одновременно по всему тексту 07b/07c: кнопка «Проверить связь»
переименовывается в «Обновить пульс» (словарь 07a), формулировки
«Проверяем…»/«Не отвечает» уходят вместе с обещанием пинга.

**Примечание — SSH-probe как будущая опция.** Прямая проверка машины
возможна только отдельным контуром: SSH-проба хоста со стороны владельца
(не «опрос агента» — агент остаётся недостижим входящими). Контур уже
наполовину существует в 07b §5.2 (SSH-ошибки мастера подключения:
`ssh.unreachable`, `ssh.host_key_mismatch` и др.). Заводить ли
SSH-пробу как действие на карточке хоста — отдельное решение
(доверительная граница, класс RCE-смежный); до него «Обновить пульс» —
единственная честная механика.

## Э2 — версия агента и каденс докладов (07c §8)

**Где.** 07c §8 «Технические детали», строки «Софт» и «Связь».
Однотипные вхождения «до 2 минут» — 07c §4 (пустое состояние ленты),
07b §5.1 (watching-экран), 07b §5.3 (таймаут мастера).

**Было (неверно).**

| Группа | Строки |
| --- | --- |
| Софт | версия агента v0.1.1 · версия харнеса · транспорт «докладывается из локальной сети» (или «через VPN») |
| Связь | «агент сам докладывается каждые ~2 мин — сервер его не дёргает» + интервал из конфига + история присутствия (last-seen trail) |

**Почему неверно.** Две ошибки в константах. Первая: актуальный релиз
агента — **0.6.0** (`VERSION` @ `dbd6054`, релиз `2e163a9` от
2026-09-29); пример-версия в спеке старше на пять минорных релизов.
Вторая: «каждые ~2 мин» — не интервал, а порог. Реальный каденс: агент
опрашивает борд каждые **10 с ± 2 с джиттер** (`poll_interval`,
PROTOCOL §2.1/§7.1), каждый такой опрос тикает присутствие
(presence-piggyback); явный heartbeat — редкий резервный путь
(бюджет 60/60 с, §3.1). Борд считает исполнителя online, пока последний
тик не старше **120 с** — вот откуда «2 мин»: это порог офлайна, а не
каданс докладов.

**Стало (готовая замена).**

| Группа | Строки |
| --- | --- |
| Софт | версия агента 0.6.0 · версия харнеса · транспорт «докладывается из локальной сети» (или «через VPN») |
| Связь | «агент сам опрашивает сервер каждые ~10 с (интервал из конфига) — сервер его не дёргает; на связи, пока последний доклад не старше 120 с (порог сервера)» + история присутствия (last-seen trail) |

Однотипные «ждём первый доклад — обычно до 2 минут» (07c §4, 07b §5.1,
§5.3) заменяются на «первый доклад — секунды после старта сервиса;
если хост молчит 2 минуты, он офлайн по порогу сервера» — то же число
остаётся, но как порог, а не как ожидание интервала.

## Э3 — discovery-блоки: только Go-агент 0.6 (07b/07c)

**Где.** 07c §6 — блок «Обнаружено на хосте» (discovery) на
approve-панели: список найденных харнесов + «Принять»
(`capabilities_source: auto-discovered`); 07c §7 — чипы умений с меткой
«найдено агентом»; 07b — шаг выбора харнеса «агент найдёт сам: он
обнаружит, что установлено».

**Что неверно.** Спека не различает исполнителей, а discovery умеет
только один из них. `POST /api/executors/{id}/discovery` (PROTOCOL §3,
v2/v3 — вплоть до инвентаря умений) отправляет Go-агент 0.6; Python-поллер
не умеет discovery вовсе (REMOTE-EXECUTOR.md: discovery — в списке того,
«чего у поллера нет»). Маршрут на борде есть, но поллер по нему не
докладывает — и не докладет до задачи **ME-056** (борд vesma-eyes).
Следствие: для хостов, подключённых через поллер (сегодня это ВСЕ хосты
пути «одна команда» — bootstrap ставит Python-поллер), блок «Обнаружено»
пуст не временно, а до ME-056.

**Стало (готовые замены).**

- 07c §6, блок «Обнаружено на хосте» — honest-empty на случай поллера:
  «Обнаружение установок умеет только агент (Go). Этот хост подключён
  поллером — список появится после ME-056.» Блок не имитирует загрузку
  (никаких скелетонов «сканируем»): пусто — это честный ответ, а не
  задержка. Для хостов с Go-агентом — как в спеке.
- 07b, шаг выбора харнеса — к «агент найдёт сам» примечание: «работает
  только на хостах с агентом (Go); для поллера выбор харнеса ручной».
- 07c §7, чипы «найдено агентом» — семантика без изменений; источник
  метки всегда discovery-факт Go-агента, у поллер-хостов таких чипов не
  бывает.
