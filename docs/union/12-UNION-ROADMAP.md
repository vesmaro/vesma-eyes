## 1. Правила объединения (не обсуждаемы, от АРХКОМ)

1. **«Одна реализация на понятие»**: движок из main, вид — из стенда. Палитра ⌘K = CommandPalette main + вид стенда; Кора = koraGatewayContext + каркас/композер стенда; honest-слоты = HonestLine main (приоритет над композициями стенда).
2. **Стенд read-only с И1**: вся живая работа в ветке слияния поверх свежего main.
3. **Golden-токены И0**: новые ключи свободно; изменение значений — осознанный golden-коммит с обоснованием.
4. **i18n**: семейства `kora/auth/tasks/settings` в main есть — строки стенда ложатся в них; новые только `living/cmdk/cockpit`; паритет ru/en — гейт не ослаблять.
5. **Бюджеты**: living-layer отдельный чанк ≤8 KiB gzip (07n §3); существующие бюджеты не размазывать.
6. **Живой слой**: при мерже каждой фазы — выключен; дефолт после включения — «Спокойный»; «Полный» — по отдельной приёмке; off-switch всегда.
7. **Процесс** (из sess_0ef2e53d): `gh` с протухшим env-токеном → `env -u GH_TOKEN -u GITHUB_TOKEN gh …`; основной чекаут занят — только `git -C`/tmp-worktree; force-push main запрещён; merge — push + squash через GWS; Node — nvm v22.22.2; деплой — только `scripts/deploy.sh` (podman-фоллбэк — норма).
8. **Процесс-дополнение (из сессии доков)**: ME-id брать после проверки занятости (свободен ME-031+); YAML борда писать ДО history.log; секреты только из `~/.secrets/` (GH_TOKEN оттуда, не печатать); каскад-ревью обязателен на trust-границах; биллинг/Actions не поднимать — CI только кластерный (директива); ME-029/030 — их открытое (CI-кластер, security-остатки style-src).

## 3. Фазы (цель → объём → шаги → гейты → откат)

**Цель:** новый каркас (топбар/сайдбар/крошки/гейты/auth/футер версии) на живом main; Кора в каркасе на реальных данных slice 1-2.

Шаги:

2. Гейты v6: auth-session hook до paint, замки, кнопки Войти/Регистрация, auth.html → React-роут (returnTo).
3. Футер версии/статуса; «Спокойный режим» переключатель-заготовка в Настройках.
4. Кора: каркас стенда (центральная рабочая зона + дерево + Пульт) поверх `koraGatewayContext` (данные slice 1-2: список, транскрипт, 401-CTA); композер — React-стейт-машина по 07j §4.6 (без персиста-черновиков в первой итерации — добавляются в И4).
5. Словарь: строки Коры в `kora.*`, гейт-строки в `auth.*` (карта 07n §4); паритет ru/en.
6. Снапшоты Shell обновляются в этом же PR (diff-ревью).

Гейты: typecheck/test/wcag/бюджеты зелёные; journey-приёмка №1 (вход → гейты → Кора на живых данных → написать агенту [поле видно, кнопка отправки появляется со статусом «появится в И4»]); регресс-набор 07n (палитра/activity/слоты/Кора/стор/И0) — pass.
