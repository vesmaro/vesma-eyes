## 0. Правила чтения карты

1. **«Одна реализация на понятие»** (АРХКОМ §1): движок — из main, вид — из
   стенда. Для каждой поверхности указано, где движок уже живёт в main и что
   именно одевается.
2. **Обозначения honest-типов** (словарь 07a, обозначения 07n Артефакт 2):
   **HL** — HonestLine/honest-строка; **«скоро»** — disabled-с-причиной слот;
   **empty-CTA** — пустое состояние с приглашением; **gate** — честный
   гейт-экран (07k §3). Числа в разметке руками = баг ревью (07j §2.2).
3. **Поправка к инвентарю 07n Артефакт 4** (сверка с кодом 1.51.0): семейства
   `cmdk.*` (17 ключей) и `cockpit.*` (17) **уже существуют в main** (волны
   1.46–1.51: CommandPalette ⌘K, cockpit-Обзор); `kora.*` вырос с 4 ключей
   среза 1 до ~40 (coverage/onboarding/list/session). Новым семейством И1
   будет только `living.*`; остальное — пополнение существующих.
4. **Внутренние коды фаз не выходят в UI**: формулировки «появится в И4» и
   т.п. — язык роадмапа; пользовательская строка говорит «появится позже»
   без кодов (07a §3.5). Соответствие — в таблицах копий §1.3.
5. **Живой слой в И1 отсутствует физически**: не выключен флагом, а ещё не
   влит. Все поверхности И1 статичны поmotion-канонам 06 (load-момент один,
   hover-тинты по токенам); дыхание/жилы — И3/И4.

- **Эталон**: `07k` §1 (точка 6px + `бренд <версия>` + `·` + статус; не

- **Honest-статус И1**: **всё реально, и сильнее стенда**: канон 07k §1.1

  ответа борда (не константа стенда). Одевается: точка цветом статуса

  Свёрнутый rail — точка + короткая версия. Возраст входа «N назад» — только
  если gate отдаёт таймстамп сессии; поля нет — строки возраста нет (не
  выдумываем). Строка не кнопка и не ссылка (07k §1.4-запрет).

#### 1.1.5 «Спокойный режим»-заготовка в Настройках

- **Дом main**: `SettingsHubPage.tsx`, секция **«Поведение»** (`behavior`) —

### 3. Четыре вопроса владельцу (фиксированные, порядок не менять)

1. «Сценарии прошли целиком, без вашей помощи?» — да/нет + где застряли.
2. «Что было непонятно или замедлило?» — место на экране + своими словами.
3. «Показать рядом, как это выглядит сейчас в main?» — да/нет.
4. «Этот вид становится единственным?» — да / нет / да после правок №…

### 4. Классификация затруднений

- blocker — намерение не завершено; данные врут; тупик без пути назад.
- major — завершено с посторонней помощью или повторными попытками;
  ожидание владельца обмануто (не там искал, не то понял).
- minor — трение без потери намерения (слово, тайминг, порядок).

Порог приёмки фазы: **0 blocker + 0 major**. Minor не блокирует — уходит
в issues следующей волны.

### 5. Вердикт и журнал

- Вердикт: принято / принято (только minor) / не принято (перечислить №).
- Issues: по одному на затруднение — id, страница, цитата владельца,
  severity, волна-исполнитель.
- Журнал: `docs/sessions/ГГГГ-ММ-ДД-phase-И1.md` — вердикт, заметки
  владельца дословно, тайминги по намерениям, список issues. Коммитится в
  той же волне.

### 6. Правило

Фаза не «done», пока файла приёмки нет в репозитории. Нет записи — фаза не
существует (даже если «всё работало на демо»).

## 4. Самокритика (проход 2)

- **«Сними бренд»**: И1 опознаётся по связке «гейт с путём назад» (гейт
  называет, куда ещё посмотреть — не пейвол), «версия из живого ответа
  борда» (не константа), «Пульт-полоса, честно пустая» (не имитация
  дайджеста), «композер без фейк-доставки». Слить с шаблонным «редизайном
  админки» нельзя — отличия не в цвете, а в честных слотах.
- **Риск: гейт-экраны без серверной стены** — снят предгейтом §3.0
  (сверка кодов; замок, который отдаёт данные анониму, = blocker). Клиент
  гейтит вид, сервер — права; двойной слой объявлен явно.
- **Риск: И1-Кора выглядит «недоделанной» против стенда** — снят развязкой:
  композиция v7 реальна, отложенное названо поимённо (§1.2.1–1.2.3), и каждый
  отложенный узел имеет фазу. Ни одного молчаливого слота.
- **Риск: модель v5 vs slice-1 шейп** — зазоры (имя сессии, shared,
  lifecycle-пилюли хоста) названы честно «нет источника — не рендерим», с
  каноном «пустой слот не рендерится». UI не договаривает за данными.
- **Токен-дисциплина**: И1 не вводит новых токенов — потребляет значения v2
  волны 1.46.0; `--kora-right-w` и персист-ключи — layout-переменные
  компонента (И3), не дизайн-токены.
- **i18n**: единственное новое семейство `living.*`; инвентарная поправка к
  07n Артефакт 4 зафиксирована (§0 п. 3) — карта не врёт о состоянии main.
