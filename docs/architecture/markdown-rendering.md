## Что действует сейчас: один конвейер, два профиля

Рендер текста — **один движок**, `viewer/src/components/TextEngine/core/`
(пайплайн = функция от режима, одна фабрика тем, одна копия hast-утилит).
Доверие — свойство канала доставки, выбирается импортом обёртки, fail-closed:

| Профиль | Обёртка | Где разрешён | Способности |
| --- | --- | --- | --- |
| `untrusted` (дефолт) | `UntrustedMarkdown` → `TextEngine/MarkdownView` | везде (примитивы) | escape-only; href/src ∈ http(s)/mailto; mermaid за жёсткими капсами (Amendment 1) |
| `curated` | `DocsMarkdown` → `features/docs/Markdown.tsx` | только `features/docs/**` (ESLint) | + raw-HTML (rehype-raw → drop → sanitize), slugs, docs-assets |

Санкционированные константы прежних правил остались в силе: react-markdown +
remark-gfm — единственная md-зависимость; только дизайн-токены; sanitize-гейт
один и применяется всегда; расширения схемы — governance-PR.
