### Added

- **Гейты v6 фазы И1 — клиентская публичная поверхность: auth-session hook до paint, замки доменов, гейт-экраны, роут входа (ME-043, union И1; спеки 07k §1–§5, карта одевания §1.1.6).** Источник истины сессии — существующий бут-зонд ui-token (ME-028: аноним = честный 200 `{"live":false}`, вердикт-набор {200,204,503}); зонд теперь уходит ДО первого рендера (`initAuthSession` в main.tsx, стор `features/ui-token/authSession.ts`, один зонд на гейтвей — провайдер присоединяется к тому же промису), закрытый контент не мигает: pending-окно держит слот нейтрально, `data-auth="anon|user"` на корне. Замки на гейт-доменах сайдбара (Память/Задачи/Агенты/Кора/Система) — честный замок со словесной причиной «откроется после входа» (07k §2.2), замок заменяет счётчик (числа — контент), строки остаются навигабельными (URL-first, без фейк-редиректов); гейт-экран в слоте контента (07k §3: H1-шаблон владельца, «что внутри», «куда ещё» со ссылкой на публичный Обзор, свёрнутый disclosure, фокус на H1, id сущностей из URL не просачиваются); роут `/auth` вне Shell хостит ту же форму входа (общий `UiTokenLoginForm` — окно и роут не могут разъехаться) с сохранением returnTo (механика `returnParams`, `/kora` добавлен в допустимые префиксы, query выживает по прецеденту ME-026) и honest-заготовкой «Создать аккаунт» (политика «первый созданный аккаунт становится владельцем», вердикт владельца 07k §10-аддендум — без фейк-флоу). Топбар: пара «Войти»+«Регистрация» для анонима; чип-пользователя нет (И2 — у токен-модели нет имени). Гейты активны только на board-адаптере: mock (без auth-стены) и mnemos L1 (чтения открыты по ADR 0011 §7) не блокируются — замок не должен врать о деплое. Сервер/токены/зонды не тронуты; серверный зазор (чтения Памяти/Задач/Агентов/Системы открыты анониму, «cluster ingress is the auth boundary» — замок опирается на продуктовую модель 07k §2.1, права остаются за сервером) зафиксирован для аудитов каскада как blocker-кандидат приёмки И1 по предгейту §3.0 карты. Словарь: семейство `auth.*` пополнено с паритетом RU/EN (копии §1.3 карты И1), футер статуса говорит «аноним»/«вы: владелец» (07k §1.2; mnemos-режим сохраняет своё «read-only»); новый i18n-гейт запрещает внутренние коды фаз в строках — заодно вычищены 5 легаси-строк с «(ADR …)» из пользовательского слоя. Verification: vitest 197 файлов / 1623 passed / 0 failed (базлайн 191/1573; +6 файлов, +48 тестов: стор зонда, таблица доменов, гейт-экран a11y, GatedOutlet, роут /auth, замки), typecheck + eslint чисто, бюджеты docs-render 7×ok (entry 255.9 ≤ 277 KiB gz, +4.8 к базлайну ME-024 — гейт-код в eager-наборе Shell), снапшоты Shell обновлены осознанно (ровно смена слова футера).
